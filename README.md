# 📖 论文阅读器

**桌面应用**（原生窗口，不需要浏览器、不需要 Node）。
划词即译、选中即问、图/表/公式框选交给 AI、正文引用可点、参考文献一键找 PDF。
PDF 不离开本机；问答默认只发送选中文字和当前页上下文，点「整篇」后才会把整篇论文作为本次上下文发送给你自己配置的 API，划词翻译和解释会发送选中文字及其附近上下文。

> **最近更新（2026-10-31）**
> - 截图附件改为**单独存文件**（`data/attachments/`）：重开论文 / 重启程序后，历史提问里的截图还在，
>   失败后「重试这次发送」也能把截图取回来直接重发；删除/清空会话时图片一起回收。
> - 右栏在大屏最宽可拖到**窗口一半**；回答文字列在宽侧栏里居中、左右留白相等，
>   文字列左右边沿还各有一个**平时隐藏、悬停才在光标附近出现的浅色渐变拖动条**（拖哪边都对称改宽）。
> - 阅读字号上限 19px → **30px**。

## 能做什么

| 能力 | 说明 |
|---|---|
| **划词** | 译 / 释 / ＋对话 / ✎笔记 / 复制；气泡和结果卡片都能拖动、能记住位置 |
| **整篇论文上下文** | 发送框上拉栏四选一：**当前内容 / 整篇论文 / 联网搜索 / 整篇论文+联网**；默认范围在设置里选，发送前可临时改、之后沿用。超过 10 万字自动降级成「阅读索引 + 关键词检索出的相关段落」 |
| **联网搜索** | 发送范围选「联网搜索 / 整篇论文+联网」时，回答前先搜一遍，来源链接列在回答下方（`[来源1]` 与论文自己的 `[27]` 区分开） |
| **读懂论文（✦）** | 四项教学能力：**先给我讲明白**（默认，几分钟讲清问题→旧办法卡点→作者办法→结果边界）、**我需要先懂什么**（只挑读懂本文必需的前置知识，标「现在必须懂 / 之后学」）、**带我一步步读**（先给路线，每次只讲一步，可继续）、**讲懂图表与公式**（默认从当前页选对象，区分事实 / 作者解释 / AI 推断）；回答里的 `〔p.N〕` 可点击跳页；「实验够不够支撑结论 / 局限与可疑之处」降级为回答末尾的深入按钮 |
| **后台学习记忆** | 不再需要手动维护知识条目：普通问答完成后**在后台**提取「持续讲解偏好 / 用户自述 / 需要帮助 / 正确表现 / 弱推断」等信息，写入本机 `data/learning-profile.json`（带写入时间与用户原话依据）；后续提问只把与当前论文/问题相关的少数条目交给模型，AI 不能自动判定你「已掌握」，遇到纠正会更新/删除原记录。可在设置里整体关闭 |
| **会话恢复与重试** | 重开论文会恢复隐藏的译文 / 问答结果，但不会强制展开；失败、停止、未完成的历史提供重试或恢复问题入口。**截图附件单独存**，所以重开论文 / 重启后历史提问里的截图和重试所需的图都还在 |
| **跨论文安全** | 切换论文时丢弃旧的全文读取 / 阅读索引；缓存命中直接定位已有结果，不重复追加结果或请求 |
| **文献关系** | 自动解析全部参考文献、跟本地书架互相匹配、扫描库内互相引用；每条可查 PDF |
| **书架管理** | 一次可选 / 拖入**多个 PDF** 批量导入；左栏文件列表按住拖动调整顺序（存 `data/papers-order.json`，不改文件名）；每行右侧 × 删除文件（会二次确认；笔记 / 会话 / 进度保留，重新导入还能看到） |
| **一键导入**（界面已下线） | 后端 `/api/import-pdf` 仍在（服务端下载、校验 `%PDF-`、挡内网地址），但界面只保留「打开链接 / 复制链接」，不再提供直接抓进 `papers/` 的按钮 |
| **公式 + 表格** | 内置 KaTeX（离线）渲染 `$...$` / `$$...$$`；Markdown 表格渲染成真表格，窄侧栏可横向滚动 |
| **自动适配** | 打开论文按窗口宽度自动铺满，窗口缩放跟着变；手动缩放过就不再抢 |

> 「读懂论文」与后台学习记忆的设计、提示词原型见 [`docs/读懂论文-设计.md`](docs/读懂论文-设计.md)
> 与 [`docs/读懂论文-示例回答.md`](docs/读懂论文-示例回答.md)（真实模型在 Attention 论文上的输出）。

## 从源码跑

```bash
# ① 浏览器模式（开发/调试用，需要 Node 18+）
node server.js            # 然后打开 http://127.0.0.1:8787

# ② 桌面应用（需要 Rust 工具链）
cd desktop
build.bat                 # cargo build --release + 复制 exe + 校验 SHA256
```

前端是**零依赖**的原生 ES module（没有打包步骤），`server.js` 只用 Node 内置模块。
desktop 端是 `wry + tao + tiny_http + ureq + rust-embed`，前端资源在编译期内嵌进 exe。

跑测试（需要 `cd test && npm i` 装 puppeteer-core；浏览器套件默认调用本机已装的 Chrome，
可用 `CHROME=` 指向别的路径）。

测试**不会碰你的 `data/`**：`test/_env.mjs` 是一道拒绝式护栏 —— 被测服务的 data 目录只要
不在 `test/artifacts/` 下面，套件会在发出任何写请求之前直接抛错退出。

浏览器套件需要一个**隔离实例**。推荐用 Node 后端：它从磁盘读 `public/`，改了前端立刻生效；
exe 的前端是编译期内嵌的，不重新 build 就还是在测旧前端。

```bat
:: ① 隔离书架 + 隔离 data（data 必须是 papers 的兄弟目录）
mkdir test\artifacts\baseline\papers
mkdir test\artifacts\baseline\data
copy test\fixtures\multipage-sample.pdf test\artifacts\baseline\papers\fixture-multipage.pdf
copy test\fixtures\cn-sample.pdf        test\artifacts\baseline\papers\fixture-cn-sample.pdf

:: ② 起服务（8787/8788 常被真实实例占着，用 8790）
set PORT=8790
set PRT_PAPERS_DIR=%CD%\test\artifacts\baseline\papers
set PRT_DATA_DIR=%CD%\test\artifacts\baseline\data
set NO_OPEN=1
node server.js

:: ③ 先塞一个假 Key —— 没配 Key 时前端根本不发请求，
::    math / cards / selection 会因此假红。
curl -X POST http://127.0.0.1:8790/api/config -H "Content-Type: application/json" ^
  -d "{\"apiKey\":\"sk-fake-for-tests\",\"baseURL\":\"https://api.deepseek.com/v1\",\"model\":\"deepseek-chat\"}"

:: ④ 逐个跑（它们共用同一个服务，别并行）
cd test
set BASE=http://127.0.0.1:8790
node e2e.mjs
```

自起服务、不依赖上面实例的（推荐直接跑这批）：`node test/ux.mjs`、`node test/r6.mjs`、
`node test/qa.mjs`、`node test/send-range.mjs`、`node test/session-bar.mjs`、`node test/attachments.mjs`、
`node test/ai-send-regression.mjs`、`node test/save-reliability.mjs` 等。

**不要跑**：
- `test/real.mjs` —— 已禁用，第 3 行就 `exit 2`；
- `test/desktop.mjs` —— 会按 exe 路径**强制结束正在运行的阅读器**，只在专门验 exe 时用；
- `isolate.mjs` / `diag*.mjs` / `smoke.mjs` —— 硬编码 8787 与固定文件名、零断言、恒返回成功，不能当门禁；
- `pack.mjs` —— 那是打包器，不是测试。

所有自动化测试都使用隔离目录、合成论文和本地假响应，不调用真实 AI API。
`test/real.mjs` 已禁用，避免误用用户密钥或产生付费请求。

## 怎么用

### 方式一：双击 `论文阅读器.exe`（推荐）

一个独立窗口，自带界面。第一次打开点右上角 **⚙**，填两样东西：

| 字段 | 例子 |
|---|---|
| API Key | `sk-…` |
| 模型名 | `deepseek-chat` |

点「保存」会自动测一次连接，通过就关掉弹窗。
把 PDF 拖进窗口（可以一次拖多个），或丢进 exe 旁边的 `papers/` 文件夹。
左栏文件列表：**按住一行拖动**可以调整顺序，行尾的 **×** 删除文件（删除前会问一次）。

> 需要**支持图片输入**的模型才能用「框选看图」（如 `gpt-4o-mini`、`qwen-vl-max`）。

### 方式二：`启动.bat`（浏览器模式，给开发和调试用）

需要电脑上有 Node.js。双击后启动本地服务并打开 `http://127.0.0.1:8787`。

## 交互

划选正文后，气泡上有五个按钮：

| 按钮 | 行为 |
|---|---|
| **译** | 直接翻译，译文就地弹在选区旁，同时进「译文」块 |
| **释** | **不需要提问**，直接在侧栏把这段讲明白（拆概念、拆符号、说明它在论文里的作用）—— 不弹浮层 |
| **＋对话** | **不发请求**，把选中的文字加进输入框上方的附件区。可以连续加很多段 |
| **✎** | 写笔记。**不会画黄色高亮**，只在页面右边缘留一个小书签 |
| **⧉** | 复制 |

**Ctrl/⌘ + 划选** = 把上一段选区拼进来一起处理（对付被图表/换栏切开的句子）。

### 截图 / 长截图

- 输入框边上的 **✂**（或按 `R`）进入截图模式
- 拖一个框 → 那一块变成**图片附件**加进对话（不会自动发问，你自己提问）
- **框拖到正文区上下边缘会自动滚动**，于是可以一路框到下一页 —— 这就是长截图。
  因为图是从 PDF 重新渲染的（不是屏幕截图），超出视口的部分也能完整拿到，
  实测一次可以拿到跨 3 页、3000px 高的长图
- 发送时图片会作为多模态内容一起发给模型（需要支持图片输入的模型）
- **点发送后图片立刻从输入区消失**，但不会丢：用户气泡里仍有缩略图，失败时附件会放回输入区；
  图片在发送时**单独存到** `data/attachments/`，所以重开论文 / 重启程序后历史提问里的截图还在，
  「重试这次发送」也能直接把截图取回来重发（详见 [使用说明书 §7](docs/使用说明书.md)）

### 正文里的 `[12]` 可以点

- 正文中形如 `[12]`、`[3,4]`、`[5-7]` 的引用会被标成可点区域（鼠标移上去会亮）
- **点一下**：跳到文末那条参考文献，并弹出它的完整条目
- **再点「🔍 找这篇的 PDF」**：去 arXiv / OpenAlex / Crossref 查它的开放版本，
  给出**可直接打开的 PDF 链接**，以及 Google Scholar / 网页搜索的兜底入口
- 查的时候先从那一条文献里**认出标题**再按标题检索；认不出来（比如只剩一个缩写字母）
  就退回整条文献串。卡片顶部会写清楚这次是**按什么搜的**
- 结果按标题相关性过滤：和标题明显不是一个东西的条目直接丢掉，
  所以「查不到」时宁可给你一条空结果 + 说明，也不会塞一堆无关论文
- 这个功能需要联网；查不到时会明确告诉你，不会假装有结果

### 笔记

- 点 **✎** → 直接弹出编辑框写想法（留空也会保存这段文字）
- **正文右边缘出现一个小书签**：灰色 = 只有收藏，蓝色 = 写了笔记
- **点书签**随时重新打开读 / 改；点到别处会自动保存
- 左栏「笔记」区可以跳转、编辑、删除
- 笔记**不会**在正文里留下黄色高亮块（避免遮挡原文）

### 快捷键

| 键 | 作用 |
|---|---|
| `T` / `E` / `Q` | 译 / 释 / ＋对话 |
| `R` | 框选区域 |
| `Ctrl+F` | 全文搜索 |
| `+` `−` `0` | PDF 放大 / 缩小 / 适应宽度 |
| `Ctrl` `+` `−` `0` | **阅读字号** 增大 / 减小 / 复位（在输入框里也生效，且不会触发浏览器整页缩放） |
| `PgUp` `PgDn` `Home` `End` | 翻页 |
| `Esc` | 关气泡 / 取消框选 / 停止生成 / 关菜单 / 关设置 |

## 界面

```
┌ 📖 文件名   ·  首页 / 读懂论文 / 全文搜索 / 左右栏开关 / 设置   窗口控件 ┐
├────┬──────────┬──────────────────────────────┬──────────────┤
│活动│ 左栏      │                              │ 译文 / 问答   │
│栏  │ 文件/目录 │          PDF 正文             │ （一栏一块）  │
│    │ 笔记/参考 │       （[12] 可点）           │              │
│    │          │                              │ ┌ 输入框 ──┐ │
│    │          │                              │ │ 发送范围  │ │
├────┴──────────┴──────────────────────────────┴──────────────┤
│ 底栏：‹ 页码 › / N  ·  缩放滑块  ·  适应宽度                    │
└──────────────────────────────────────────────────────────────┘
```

- **顶栏就是应用内标题栏**（VS Code 风格，常驻）：文档名、首页、读懂论文、全文搜索、左右栏开关、设置；
  翻页 / 缩放整组在**底栏**，顶栏不再重复。
- **左右两栏都能拖动边界调宽**，宽度会记住；拖到阈值以下松手即收起，双击分隔线切换收展；
  大屏幕上**右栏最宽可拖到窗口一半**。
- **窗口放不下时自动收起**：正文有最小可用宽度（`--viewer-min`，默认 420px）；放不下时先收右栏、
  再收左栏，窗口变宽按你的意图恢复（自动收起只存内存，不写进偏好）。
- **左栏**：常驻最左侧细活动栏（文件 / 目录 / 笔记 / 参考文献）；点哪个展开哪个，一次只显示一块。
  支持拖入多个 PDF、按住行拖动排序、行尾 × 删除文件。
- **右栏恒为一列**（译文 / 问答二选一，顶部切换器）：一栏只开一块；问答块底部是输入框
  （带「发送范围」芯片），输入框上方是附件区（选中的文字、截图）。
- **问答文字列**：在宽侧栏里居中、两侧留白相等；左右边沿各有一支**平时隐藏的拖动条**，
  鼠标贴上去才在光标附近出现一小段浅色渐变条，拖任意一侧对称改宽（宽度会记住）。
- **文献关系**：按 书架已有 / 已找到开放版本 / 待查·未找到 / 被引用 分组（带计数、可折叠），
  支持搜索 / 状态筛选 / 排序；点一行打开详情（条目全文、书架匹配、开放版本链接、跳回正文、复制引用）。
- **结果区以正文为主体**：正常回答不显示「回答完成」；页码 / 原文引用 / 底部操作条默认降低对比度，
  鼠标移上去才恢复。**选中的文字是自己画的方块**，上下不会重叠。
- **设置页只剩高频项**：API Key / 模型 / 接口地址、主题、阅读字号（12–30px）、双指缩放速度
  （触摸屏与触摸板共用，0.5×~2×，当场生效）、默认发送范围、恢复默认设置。
  早期的「更多样式 / 结果密度 / 面板管理器 / 浮动面板 / 独立窗口 / 多列右栏」都在后续几轮按用户口径删除了。
- **主题**跟随系统（浅色 / 深色自动切换），也可以手动指定；公式 / 表格离线渲染（KaTeX + 真表格）。

## 目录结构

```
prt/
├── 论文阅读器.exe          桌面应用（双击即用；也可自己 build，产物不进仓库）
├── 启动.bat / start.bat    浏览器模式（开发调试用）
├── server.js               Node 版后端（零依赖）：静态托管 + AI 转发 + 联网搜索 + 文献检索 + PDF 导入 + 存储
├── security.js             服务端安全模块（server.js 与多套测试共用）
├── model-profiles.js       模型预设（Node 版后端用）
├── desktop/                Rust 桌面壳：原生窗口 + 内嵌前端 + 同款 HTTP 接口
│   ├── src/{main,window,server,api,chat,store,assets,auth,limits,util}.rs
│   ├── build.bat           一键编译 + 复制 exe + 校验 SHA256（会先碰 assets.rs，保证新增前端文件被嵌进去）
│   └── tools/              假 OpenAI 服务、验收脚本
├── public/                 前端（桌面版与浏览器版共用同一份，零依赖、无打包）
│   ├── index.html  style.css
│   ├── js/{app,pdfview,ai,util,ops,teaching,profile,learning-memory,icons,reading-context}.js
│   │                       teaching.js = 「读懂论文」四项能力的 prompt 与 prt 协议；
│   │                       profile.js = 学习档案存储/校验（时间戳/当前时间注入）；
│   │                       learning-memory.js = 后台学习记忆（问答完成后自动提取/合并）；
│   │                       ops.js = 深入阅读两条
│   └── vendor/             pdf.js + KaTeX（都本地内置，不走 CDN）
├── papers/                 放 PDF（不进仓库）
├── data/                   运行时：config.json（含密钥）、state.json、notes-*.json、
│                           attachments/（截图附件单独存，不进会话 JSON）（不进仓库）
├── test/                   自动化测试（40+ 个 .mjs：套件 + perf 调研脚本，见「测试」一节）
├── docs/                   长期文档：PROGRESS / 使用说明书 / 触摸屏缩放丝滑化 / 读懂论文设计与示例
│   └── archive/            历史过程文档（交接提示词、审计清单、旧设计稿…共 15 份）
├── backup/                 本机快照（不进仓库）
└── AGENTS.md               给接手的人（或 AI）看的项目约定
```

## 隐私

- 只监听 `127.0.0.1`，不对局域网暴露（实测局域网 IP 访问超时）
- PDF 解析、渲染、区域截图全在本地完成，**PDF 本身永不上传**
- 只有你主动划选的那段文字 / 主动框选的那块图片会发给你自己的 API
- 框选的截图附件保存在本机 `data/attachments/`（**单独存文件**，不进会话 JSON、也不上传到第三方）；
  删除 / 清空会话时一起回收
- 只有点「找这篇的 PDF」时，才会把**那一条参考文献的文字**发给 arXiv / OpenAlex / Crossref 检索
- 密钥只写在本机 `data/config.json`，不进浏览器 localStorage、不经第三方
- **密钥填一次就一直有效**：关掉窗口、重新打开、换论文都不用再填；想换一把就直接在 ⚙ 里粘贴新的覆盖
- 自动化测试不会再动你的配置（`test/_env.mjs` 要求被测服务的 data 目录必须位于 `test/artifacts/` 下，否则直接拒绝运行）
- 想完全离线：把接口地址改成 `http://127.0.0.1:11434/v1`（Ollama），文献检索不用即可

## 已知限制

- **扫描版 PDF** 没有文本层，划词无效 → 用「⎚ 框选」把那块区域交给视觉模型（整篇 OCR 已在 2026-10 移除）
- **双栏排版**跨栏划选可能把两栏文字混在一起（按列重排未做）
- 引用跳转依赖 PDF 文本层里的 `[n]` 编号和文末文献列表；**作者-年份制**的引用（如 `(Vaswani et al., 2017)`）暂时点不了
- 文献检索靠三个公开接口，**需要联网**；冷门文献或有付费墙的论文可能只有 DOI 落地页，没有免费 PDF
- 一次只能开一篇论文
- 扫描版交给视觉模型时会逐块发图，**页数多的论文会比较慢**，而且需要支持图片输入的模型

## 为什么长这样

完整调研见 [`docs/archive/RESEARCH.md`](docs/archive/RESEARCH.md)。一句话：

> 「开源 + 划词 + 本地 + 自带阅读器」这个组合，在调研范围内不存在 —— 做划词的都要装 Zotero 或没有阅读器，
> 做全文对照的全是 Python + ONNX 的离线批处理，闭源阵营全是把论文上传到云端的 SaaS。
