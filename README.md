# 论文阅读器

Windows 桌面端的 PDF 阅读器，带 AI 辅助：划词翻译/解释、整篇论文问答、框选图表交给模型、
参考文献检索。PDF 和会话都留在本机，AI 请求发给你自己配置的 OpenAI 兼容接口。

## 下载

- 发布页：<https://github.com/975952/paper-reader/releases>
- 应用（Windows 10/11，免安装）：`paper-reader.exe`，双击运行。

仓库是 private，下载需要登录有权限的 GitHub 账号。第一次打开后在设置里填 API Key 和
模型名（任何 OpenAI 兼容接口都行，例如 DeepSeek）。

## 功能

- 划词：翻译、解释、加入对话、写笔记、复制。**右侧问答回答 / 译文里的文字也能划词**，
  同样可以「加入问答」「直接解释」「复制」。
- 问答：把选中文字或截图作为附件提问；发送前可选范围：当前内容 / 整篇论文 / 联网搜索 / 整篇 + 联网。
- 扫描版 PDF：打开时自动判定页型；没有文本层的论文按**页面图片**理解（问答与「读懂论文」都可用，
  第一次做教学能力时会逐页生成图片阅读索引并缓存）。截图 / 页图会交给设置里的**视觉模型**（可选）。
- 记忆：同一会话的滚动摘要、这篇论文之前的讨论摘要、设置里可手写的**长期记忆**；
  后台学习记忆会自动提取**身份自述（称呼/名字、研究方向）**、讲解偏好和理解边界，后续回答参考。
- 截图：框选区域或长截图（拖到边缘自动滚动），作为图片附件发给支持视觉的模型。
  截图单独存在本机，重开论文后历史提问里的截图仍在，失败重试也能直接取回重发。
- 读懂论文：四项教学式回答——讲明白、前置知识、一步步读、讲图表与公式；回答里的页码可点击跳转。
- 多会话：每篇论文可建多个问答会话，支持恢复、重试（含截图）。
- 文献：正文里的 [12] 可点，跳到参考文献；可查开放版本 PDF。
- 阅读：目录、全文搜索、笔记书签、缩放 / 适应宽度。
- 左栏文件树：新建 / 重命名 / 删除文件夹，文件与文件夹都能拖拽排序、拖进文件夹，支持批量导入。


## 运行

浏览器模式（开发调试）：

```
node server.js        # 需要 Node 18+，然后打开 http://127.0.0.1:8787
```

Windows 也可以双击根目录的 `start.bat`（会检查 Node 并启动同一个服务）。

桌面版：

```
cd desktop
build.bat             # 需要 Rust 工具链
```

前端是零依赖的原生 ES module，没有打包步骤；`server.js` 只用 Node 内置模块。
桌面外壳用 wry + tao + tiny_http + ureq，前端资源编译期内嵌进 exe。

## 测试

```
cd test
npm install
node ux.mjs           # 各套件会自己起隔离服务，不碰 data/ 和 papers/
```

新增/重点套件：

```
node right-select.mjs   # 右栏划词（加入问答 / 直接解释）
node scan-pdf.mjs       # 扫描件判定、页图上下文、图片阅读索引
node memory-session.mjs # 会话滚动摘要 / 本篇讨论摘要 / 长期记忆
node desktop.mjs        # 沙箱副本 exe 验收：窗口隐藏、不抢焦点、不碰正在用的应用
```

测试与构建**不会关闭你正在用的应用**：`desktop.mjs` 只启动 `test/artifacts` 里的 exe 副本
（`--background` 后台模式，窗口不可见），`build.bat` 也不会按进程名杀进程；
桌面副本被占用时只打印提示并跳过。测试套件清单与逐轮验收记录见 `docs/PROGRESS.md`。

## 目录

- `public/` 前端（桌面版与浏览器版共用）
- `server.js`、`security.js`、`model-profiles.js` Node 后端
- `desktop/` Rust 桌面外壳
- `test/` 自动化测试
- `docs/` 文档（使用说明、设计记录、历史归档）
- `data/`、`papers/` 运行时数据，不进仓库

## 隐私

- 服务只监听 `127.0.0.1`。
- PDF 不上传；只有你主动选中的文字或框选的截图会发给你配置的模型接口。
- API Key 只写在本机 `data/config.json`。
- 截图附件单独存在 `data/attachments/`，清空或删除会话时一起删除。

## 已知限制

- 扫描版 PDF 没有文本层，划词不可用，需要用框选交给视觉模型。
- 双栏排版跨栏划选可能混字。
- 作者-年份制引用（如 Vaswani et al., 2017）目前点不了。
- 需要自己准备 API Key；没有网络时只能使用阅读、搜索、笔记等本地功能。
