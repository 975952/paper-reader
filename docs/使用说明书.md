## 1. 五分钟上手

| 步骤 | 做什么 |
|---|---|
| ① 打开 | 双击 `prt.exe`（绿色版，免安装）|
| ② 填密钥 | 右上角 ⚙ → 填 **API Key** 与 **模型名** → 保存。（不填也能看 PDF，只是 AI 功能不可用）|
| ③ 放论文 | 把 PDF 拖进左栏虚线框，或点左栏「＋ 选择 PDF」 |
| ④ 读 | 滚轮翻页；需要工具条时把鼠标移到**屏幕最上沿**，顶栏滑出 |
| ⑤ 用 AI | **划一段文字** → 浮出小气泡 → 点「译 / 释 / 对话」，或直接按 `T` / `E` / `Q` |

> **同一个数据目录只允许开一个阅读器窗口。** 再次双击 exe 会把已打开的窗口提到前台并提示，不会启动第二个——
> 两个窗口会抢同一份 `data/` 和 WebView2 缓存，可能互相打断（打开文档失败、会话记录互相覆盖等）。
> 想同时对比两套完全独立的数据，把 exe 复制到另一个目录（各带自己的 `papers/`、`data/`）即可。

## 2. 打开与管理论文

### 2.1 文件放哪
- 绿色版：`papers/` 与 `data/` 都在 **exe 所在目录**。
  - `papers/` = 你的论文库；`data/` = 配置、笔记、阅读状态。
- 直接把 PDF 拷进 `papers/` 也会被列出（顺序不会自动重排：新文件追加在列表末尾，之后只有你手动拖拽才会改变顺序）。

### 2.2 三种打开方式
1. **拖拽**：把 PDF 从资源管理器拖到左栏的虚线框（`拖入 PDF，或点击选择`）。
2. **点选**：点虚线框 → 系统文件框选 PDF。导入的 PDF 会**存进 `papers/`** 并出现在列表里。
3. **点列表**：左栏文件列表里点一下即开。

### 2.3 文件列表
- **筛选**：列表上方输入框 `筛选文件…`，按名字即时过滤。
- **当前文档名**：顶栏左侧显示，未打开时是「未打开文档」。
- **顺序不自动排序**：列表顺序 = 你手动拖拽排好的顺序（存在 `data/papers-order.json`）；
  新导入 / 新拷进 `papers/` 的文件**追加在末尾**，不会因为修改时间被插到最前面。
- **拖拽排序 / 移动**：按住某一行拖到同目录另一行上 = 调整顺序（**文件夹里的文件也能拖**）；
  拖到文件夹行 = 移进去；拖到列表空白处 = 移到根目录（**要拖够远才算**，轻轻一拖、或者松手落在自己那一行上，位置不变；
  在文件夹自己的空白区松手 = 不动，不会把文件甩出去）。
- **多选（批量操作）**：
  - `Ctrl/⌘ + 点击` 加选 / 取消，`Shift + 点击` 按区间多选；
  - 按住某行**最左边的细条**（鼠标变成十字）拖出矩形，矩形碰到的文件都会被选中；
    也可以从列表空白处按住拖动框选；
  - **多选后按住任意一个选中文件拖动** = 整组移动：拖到文件夹行 / 根目录空白处，所选文件一起移动；
  - 选中多个后**右键** → `删除所选` / `移动到…`（选目标文件夹）；也可以直接按 `Delete` 批量删除；
    `Esc` 或点列表外清空多选。
- **上次读到的位置会自动恢复**：重新打开软件会直接回到上次那篇论文与页码。
- **自动识别扫描件**：打开时会在后台判定页型（每页有没有文本层，不阻塞首屏；上千页的大文件只抽样检查）。
  整篇没有文本层的论文会被标成「扫描件」，问答和「读懂论文」自动改用**页面图片**理解
  （见 §5.7），并在输入框下方写明「按页面图片理解」（不再弹窗）。
- **大文件**（几十 / 上百 MB、几千页）：打开时只按需读取当前需要的页和字节范围，**不会先把整个文件拉下来**；
  页尺寸分段测量、页型判定抽样，跳远页时只补目标页附近的尺寸。实测 30MB/800 页约 0.8 秒、
  150MB/2000 页约 0.9 秒、300MB/3000 页约 1.1 秒出首屏，跳远页约 0.1 秒。
- **翻页预加载**：停在某一页时，后台会把你**接下来十几页**先画好（往回也补几页），翻页 / 滚动时目标位置已经有画面，不用等；
  已渲染的页数有回收上限，不会越翻越占内存。

### 2.4 首页书架（没有打开文档时）

- 没有打开任何论文时显示首页：顶部是「继续阅读」卡片（有阅读记录时），下面就是**书架**。
- 书架**按文件夹分组列出 `papers/` 里全部论文**，不再是混在一起的一堆最近记录：
  根目录显示为 `papers/`，子文件夹各自一组并逐级缩进；每组后面标着这一组有几篇。
- 每行：文件名 + `第 N 页 · 时间`（读过）或「未读」；点一行直接打开。
- 有阅读记录的行右侧有 `×`：只移除「最近阅读记录」，**不会删除 `papers/` 里的文件**。

## 3. 阅读与翻页

### 3.1 顶栏（鼠标移到屏幕最上沿才出现）
- 默认**悬停才出现**：鼠标移到屏幕最上面那条窄带，顶栏滑出；移开自动收起。
- 想让它一直显示：⚙ → 设置 → **顶栏** → 选「常驻」。
- 顶栏滑出**不会让正文移动**（它是浮层），也不会盖住正文内容。
- 顶栏右侧有 **⛶ 全屏** 按钮（快捷键 `F11`）：窗口铺满整个屏幕（盖住任务栏），
  应用内顶栏 / 底栏和正常窗口时一样保留；**按 `Esc` 退出全屏**。
  从「最大化」状态进入全屏也正常（不会在任务栏位置留黑条 / 白边）。

### 3.2 页码
- `‹` / `›` 按钮上一页 / 下一页。
- 中间那个页码框**可以直接输入数字**，回车跳转。
- `/ N` 是总页数。
- 顶部右侧状态栏（屏幕最下沿）显示当前页与加载进度。
- 双页显示时页码显示当前这一行**左边那页**，翻页按钮一次翻两页（见 §3.6）。

### 3.3 缩放
- 滑块：`25%` – `500%`。
- `－` / `＋` 按钮微调。
- **适应宽度**按钮：把页面宽度撑满阅读区（推荐，读论文最舒服）。
- `0` 键 = 适应宽度；`+` / `-` = 放大 / 缩小。

### 3.4 返回原位置
跳转（点目录、点搜索结果、点引文）之后，顶栏会出现 **↩ 返回原位置** 按钮，点一下逐步退回跳转前的位置。
> 相关按钮上的「返回原位置」「跳回正文」也做同一件事。

### 3.5 阅读位置记忆
每篇论文**各自记住**读到哪一页；`←` 返回后仍在原处。状态存在 `data/` 里，不需要手动保存。

### 3.6 双页显示（两页并排）
- 底栏「大小」那一排最右边有个 **▥ 双页** 按钮：点一下变成两页并排（再点一下回单页）。
- 双页时按新宽度重新适配：每页占一半宽，适合宽屏 / 大屏对照看；`‹` / `›` 和 `PageUp` / `PageDown`
  **一次翻两页**（翻一行）。
- 页码显示这一行左边那页；在页码框输入数字跳转后，会把这一行两页一起显示出来。
- 选择会记住：下次打开还是双页；想回单页再点一次按钮即可。

## 4. 划词：翻译 / 解释 / 加进对话 / 笔记

在正文里**划选一段文字**，会在选区旁浮出一个小气泡：

| 气泡按钮 | 作用 | 快捷键 |
|---|---|---|
| **译** | 翻译成设置里的目标语言，结果显示在右侧「译文」栏 + 就地浮层 | `T` |
| **释** | 直接解释这段（不翻译），显示在右栏 | `E` |
| **对话** | 把这段**加进对话**当上下文，可连续加多段 | `Q` |
| **笔记** | 写一条笔记（页边留小书签，**不加黄色高亮**） | — |
| **复制** | 复制选中文字 | — |

### 4.1 多段拼接
按住 **Ctrl（Mac 为 ⌘）再划选**，会与上一次选区**拼接**成一段 —— 用于跨栏、跨页地攒一段上下文再一次性提问。

### 4.2 翻译的细节
- 翻译会带上**页面上下文**（同一页附近的文字），术语更准。
- 同一段文字翻过会**走缓存**，再翻一次是秒回（提示「这段翻过，直接用缓存」）。
- **译文栏底部有常驻输入框** —— 直接粘贴文字翻译用（见 §4.6）；要提问请切到「问答」。

### 4.3 笔记
- 气泡里点「笔记」→ 弹窗写正文 → **保存**（或 `Ctrl+Enter`）。
- 关窗即自动保存；留空也会保存这段原文引用。
- 笔记出现在左栏「笔记」块，点条目跳回原文位置。

### 4.4 右栏文本也能划词（问答回答 / 译文）

在**右侧问答回答、解释结果、教学结果或译文**里选中文字并松手，会浮出同一个气泡，但只保留三个按钮：

| 气泡按钮 | 作用 |
|---|---|
| **加入问答** | 把这段文字加入当前问答的附件（标注来源「右栏」），可以继续加多段 |
| **直接解释** | 就这段文字提问 / 解释，结果回到问答区；如果问答区还停在「选择会话」卡片上，会先打开最近用过的那段会话，再把解释接在后面 |
| **复制** | 复制选中文字 |

右侧划词不显示「翻译 / 写笔记」（笔记需要正文锚点）。快捷键照旧：选中后 `E` = 解释、`Q` = 加入问答、`T` = 翻译。

> 在译文里划词点「解释」时，如果问答面板还没选会话（显示着「继续上次 / 新建会话」卡片），
> 会先自动打开**最近活动的会话**再把解释写进去；一个会话都没有才新开一个。
> 这样解释不会落进看不见的空会话，也不会在之后选会话时被覆盖掉。

> 右栏是**对话文字**，不是 PDF 原文：从回答 / 译文里划的词加入问答时不会标页码，AI 也会被告知
> 「这段来自右栏，不是论文原文」，不会拿它去对照某一页的原文。要引用论文原文，请在正文里划选。
在正文和右栏之间切换选区时，旧气泡会自动收起。

### 4.5 截图翻译（框选图表 / 公式直接翻）

正文里的**图、表、公式、扫描页**往往没有可划选的文字层，这种情况用截图翻译：

1. 切到右栏 **译文** 面板，点面板顶部的 **⌖ 截图翻译**（或按 `R` —— 在译文面板里按 `R` 自动走截图翻译）。
2. 拖动框住要翻的区域，松手后截图会**放进底部输入框**（和问答加图一样），按 `Enter` 开始翻译；拖到阅读区上下边缘会自动滚动，可以框成长截图。
3. 结果直接进**译文面板**，条目上带这次框选的**缩略图**，方便对照原图阅读；
   公式、变量、数字、引用编号、图表编号会原样保留；以图表为主时末尾会给一行「图表说明：…」。

补充说明：

- **目标语言跟随输入框旁的「译成」选择**（默认中文）：改成 English 后，划词翻译、截图翻译、文本翻译
  的提示词、条目上的方向行（`原文 → English`）和实际输出都会用英文；改回中文立即生效。
  重试 / 刷新恢复的旧条目沿用当时记录的目标语言。（2026-11-05 修复：以前截图翻译写死中文、
  划词翻译自动判断方向，导致切了 English 仍出中文）
- 截图翻译需要**视觉模型**（在 ⚙ 设置里配 `visionModel`）；模型看不了图时条目标题会明确提示，不会瞎猜内容。
- 失败或被停止时条目下方有 **重试截图翻译**：原图已单独存在本机，重试不用重新框选。
- 截图原图存在 `data/attachments/`（会话文件里只记编号），**重开论文 / 重启程序后译文与缩略图都还在**。
- 截图翻译结果和划词译文一样按论文保存；**「清空当前会话」只清问答与 AI 功能结果，不动译文**。
- 划词翻译与截图翻译互不影响：正文可选中时优先用划词（更快、有缓存），选不中或整块图表时再框选。

### 4.6 文本翻译（直接粘贴 / 输入文字来翻）

除了划词和框选，也可以直接输入要翻译的文字：

1. 切到右栏 **译文** 面板，底部输入框始终可见；无需额外打开文本翻译窗口。
2. 粘贴或输入文字（最多 2 万字），在输入框旁的「译成」选择中文或 English（会记住上次选择）。
3. 截图附件预览与问答一样显示在输入框边框内；按 `Enter` 开始翻译，`Shift+Enter` 换行。输入框与问答共用，**字号也直接跟问答输入框一致**（跟随 ⚙ 设置里的「界面字号」），没有单独的译文输入字号。
4. 框选截图也会先进入这个输入框：带截图时按 `Enter` 就翻译截图（也可以同时输入要翻译的文字），一张截图一条译文，条目上保留缩略图。

- 译文结果**沿用问答消息的排版**：一行轻量语言方向、灰色原文参照，正文用和问答回答相同的阅读字号（跟随「阅读字号」设置），截图同样按问答的图片尺寸显示——不再套额外的译文卡片。
- 条目下方可**复制译文**。划词、截图和文本翻译结果都汇入译文面板。
- 与划词 / 截图翻译共用同一条翻译管线，结果按论文保存，重开论文 / 重启程序后还在。
- 目标语言默认中文，可在输入框旁切换；**这个选择同时作用于划词翻译和截图翻译**，方向行与输出保持一致。
  失败或被停止时条目下方有重试按钮，不用重新输入；重试沿用当时的目标语言。
- **「清空当前会话」不动译文**（译文按论文单独存，与问答会话无关）。

## 5. 读懂论文：四项 AI 能力与后台记忆

点顶栏的 **✦ 读懂论文** 按钮，弹出四项教学能力。学习记忆在后台自动维护，无需另填表格。
它们解决的是「我现在读不懂」——不再是「给一个结论」；结果回到右栏问答区，可以接着追问。
其中「先给我讲明白」的讲法由 AI 结合论文内容、阅读位置与记忆自己判断（见 §5.1），其余三项是固定能力。

**点击后的行为（2026-11-03 起）**：

- 还没打开会话（打开文件夹时看到的是选择卡片）→ 自动新建一个会话，然后直接生成；
- 当前打开的会话里**已经有这一篇论文的这条结果** → 直接定位过去（闪一下），不会重复生成；
- 当前会话里没有，或那条结果属于**别的论文 / 别的会话** → 直接重新生成；
- 菜单里不再显示「已生成」，也不会因为生成过而变色；想重跑就点结果下方的 **重新生成**。
- 结果按「属于当前这篇论文」来认，不会把上一章或另一篇论文的旧记录当成命中。

### 5.1 先给我讲明白（讲法由 AI 判断）

这一项的讲法**不是固定模板**：AI 会结合三样东西自己判断该怎么讲，然后直接开始——

1. **论文实际内容**：主线问题是什么？关键定义、公式、图表、实验在哪些页？
2. **你的记忆**：学习画像里你已懂到什么程度、哪些地方有困难、讲解偏好（先直觉还是先公式）、长期记忆与身份、
   这篇论文之前的讨论摘要、本次会话最近聊过什么；
3. **你现在的阅读位置**：当前第几页（读到中途就不会再从标题讲起）、当前页有哪些图表公式、有没有选中文字。

它可能给出的讲法（由它自己挑，不问你）：

- 首次打开、没有更多信号 → 入门讲解：它要解决什么问题 → 一个具体例子（标「教学例子」）→ 原来卡在哪 →
  作者的办法（直觉 + 关键定义 / 1–2 个核心公式）→ 结果和边界；
- 记忆显示某类前置知识是硬门槛、你也有困难 → 先讲最关键的前置点，再给全文路线；
- 你已经读到中途（或之前讲过）→ 接着当前进度 / 当前页讲，不会重复总览；
- 当前页有关键图表 / 公式 → 讲懂它。

开头可能有一句「这次我先讲…」说明它的选择。回答末尾照样可以点：`讲简单一点`、`给个例子`、`再压短`，
以及深入阅读的 `看实验够不够` / `它有什么局限`。本轮讲解也会进入会话记忆，之后追问（「继续」「这里没懂」）
会接着它讲，不会从零开始。

### 5.2 我需要先懂什么

只挑**读懂这篇论文真正必需**的 3–5 项前置知识（不是学科清单）。每项说明：
它是什么、本文为什么需要它（标页码）、**理解到什么程度就够**、以及「现在必须懂 / 可以之后再学」。

- 清单一出来，每项就是一个按钮（如「讲第 1 项」）；点开才讲，不会一次灌完。
- 单项讲解结尾会**回到论文原文**，告诉您现在再读那一段应该能看懂什么。
- 讲完可以点 **这里没懂**，立刻换更基础的说法重讲；也可以直接通过对话表达自己会什么、卡在哪里。

### 5.3 带我一步步读

先给 5–7 步的阅读路线（按理解依赖排序，不机械照搬章节顺序），然后**只讲第一步**。
每步包含：现在要弄懂的问题、去读哪一页、核心解释（必要时小例子）、与下一步的联系。

- 点 **继续下一步** 才会推进；点 **讲简单一点 / 给个例子** 只重讲当前这一步。
- 进度随会话保存，重开论文还能接着读；菜单里会标「进行到第 N 步」。
- 中途可以随时自由提问，回答后**不会擅自推进**到下一步。

### 5.4 讲懂图表与公式

默认从**当前阅读页**找对象，不默认分析整篇：

- 当前页有多个候选时，先让你按「图 2 / 表 1 / 公式 (1)」选一个（`看全文的图表清单` 兜底）；
- 图：先说它想表达什么，再讲坐标 / 图例 / 曲线 / 模块和阅读顺序；
- 表：先说比较对象，再讲每列指标含义、数值往哪个方向好、在什么条件下比、能得出什么结论；
- 公式：先说它计算/描述什么，再逐个符号解释、讲运算关系（必要时一组简单数值走一遍）。

它会严格区分「图表直接展示的事实 / 作者正文里的解释 / AI 的推断」。PDF 里图内文字抽不到时，
会明确说缺什么，**不会补造**。

### 5.5 深入阅读（不占菜单）

「实验够不够支撑结论」「局限与可疑之处」不再是入口：它们出现在「先给我讲明白」回答末尾的
按钮里（`看实验够不够` / `它有什么局限`），需要时点一下即可，结果同样进问答区、可缓存。

### 5.6 后台学习记忆

正常提问时，系统在回答结束后自动整理相关的学习信息。界面不显示知识条目、数量或确认弹窗，也不需要手动编辑。

- **记什么**：① 你明确自述的**称呼/名字、研究方向、长期目标**（例如「我叫 Cyan，请记住」）；
  ② 持续的讲解偏好；③ 知识点的具体理解边界。三类都只来自你当前的原话，附原话依据与时间；
  联系方式、账号、密钥等敏感信息不会被记录。
  其中「我叫…请记住 / 请记住称呼我…」这类明确要求**在发送当时就记住**，不依赖模型提取是否成功。
- **怎样纠正**：直接说“你记错了，这个我还不会”；需要忘记某项信息时可以说“忘记我会矩阵乘法这条记录”
  或“忘了我的称呼记录”。明确的新表达优先于旧观察。
- **讲过不等于掌握**：听过讲解、点击继续或读了很久都不会自动升级掌握程度。只有相关信息会影响下次讲解；
  论文专属的困难不会带到另一篇论文，但称呼/方向这类身份信息是跨论文的。
- **怎样保存**：沿用本机的学习记录文件，跨会话和程序重启保留；阅读进度仍按论文、会话分别保存。记录不进入源码包或 Git。
- **模型调用**：符合条件的对话会额外执行一次有长度与超时限制的后台提取；相关记忆和有限的对话片段会发送给配置的模型。后台失败不影响主回答。
- **想确定永久生效**：⚙ 设置里的「长期记忆」是手写层，优先级更明确；后台自动记忆负责“不用你动手”的那部分。

自动观察可能有遗漏或误判，当前对话中的反馈仍然优先；不会据此给出“全面掌握”的结论。

### 5.7 扫描版 PDF（图片理解）

扫描件没有文本层，划词、全文搜索、页码定位都用不了，但问答和四项教学能力仍然可用：

- 打开时自动判定；整篇没有文本层的论文会在输入框下方写明「按页面图片理解」（不弹窗）。
- **问答**：自动把当前页（整篇类问题会带首尾/代表页，最多 5 页）的页面图作为上下文发给**视觉模型**
  （图片和文字在同一条消息里发给同一个模型，由模型内部融合理解，应用不做 OCR）；
  输入框上方的范围提示会写「页图 N 张」。
- **读懂论文**：不再做逐页 OCR 转写，直接按问题带相关页的**页面图片**给模型（整篇类能力会带首尾/代表页）；
  第一次也不再等「逐页转写」。
- **图表与公式**：扫描页按整页图交给视觉模型讲。
- **视觉模型**：设置里「视觉模型（可选）」填一个能读图的模型；留空则用主模型。
  主模型支持读图时（如 deepseek-flash）直接可用；不支持时会报错/明确说看不到图片。
- 页面图按论文文件指纹缓存，文件没变就不会重复渲染/重复花钱；扫描件仍可用框选截图（§7）。
- 独立的「本地 OCR / 生成文字版」目前**不提供**（按用户要求移除）；需要逐字引用时用框选截图或视觉模型读页图。

### 5.8 共同底线（所有教学回答都遵守）

- 只依据给出的论文材料作答，材料里没有的会明说「给出的内容里没有提到」；
- 论文事实标来源页码，写成 `〔p.3〕`（和论文自己的参考文献编号 `[27]` 区分开），
  **页码可以直接点，点了跳回原文那一页**；
- 中文为主，术语首次出现保留英文原词；公式用 LaTeX（离线 KaTeX 渲染）；
- 先直觉后定义、不做无意义的堆砌；结果回到右栏成为一条带能力名的条目，可以「重新生成」。

## 6. 智能问答（右栏对话）

### 6.1 怎么问
- 右栏切到「问答」→ 底部输入框打字，**Enter 发送**（`Shift+Enter` 换行）。
- 或先划词按 `Q` 把原文塞进对话，再打字提问。

### 6.2 发送范围（设置里的默认值）

发送范围**不再放在输入框旁边**（2026-11-04 移除；AI 现在会自己翻页读论文，「当前内容 / 整篇论文」的临时切换意义很小）。
默认值在 ⚙ → 设置 →「交互与发送」的两个勾选里，改完立刻生效：

| 默认项 | 作用 |
|---|---|
| **整篇论文** | 每次提问默认把论文全文作为材料一起发（长论文自动用阅读索引 / 相关段落；扫描件 = 采样页图）。AI 自己翻页读论文时一般不用开 |
| **联网搜索** | 每次提问默认先联网查一次资料（带论文片段） |

两个都勾就相当于以前的「论文 + 联网」。输入框下方只保留一行只读提示，说明这次实际会带什么。

同一分类里还有一个 **连贯追问直接回答**（默认开）：明显接着上一轮问的短问题（没加选区 / 截图）
直接用前文回答，不再重新翻页、带页图、跑多轮工具思考，速度明显更快；但只要问题里点名
「查 / 翻页 / 第 N 页 / 前面几页 / 其他页 / 原文 / PDF / 核对」、对上一轮回答只回一个「？」、
或点「重新生成」，就会**自动切回完整阅读流程真正去翻页核对**（不会反过来让你自己贴材料）。
关掉它以后每个问题都会重新读材料（更慢、更稳）。细节见 §6.3。

问答栏顶部是**会话头**（会话系统 2026-11-03 起是一等公民，详见 §16.4）：

- **标题按钮**：点开快速切换浮层——最近的会话、搜索、查看全部；
- **＋**：新建会话；
- **☰**：打开会话历史面板——搜索、置顶、归档、重命名、删除（应用内确认），
  **「按文件 / 按时间」两种排列**（见 §16.4），面板底部还有**会话设置**入口（换论文时对话怎么接、打开文件夹时、历史排列、AI 自动标题，见 §12.5）；
- **状态点**：AI 正在生成时亮起；生成中点新建 / 切换 / 删除会被拦住并提示，不会把正在生成的会话丢掉；
- 历史面板底部还有**清空当前会话**（只清对话与 AI 结果，论文、笔记、译文不受影响）和**本篇对话记忆**（见 §6.4）。

> 「换论文时对话怎么接」可以在 ⚙ → 设置 →「会话」里选（默认「按文件夹」：同一文件夹里的论文接着同一段对话）：
> 另有「按论文」（每篇论文各接自己那一段）和「全局共用」（所有论文接同一段），见 §12.5 / §16.4。
> 右栏译文仍按论文各自保存（见 §16.4）。旧的分论文会话在第一次打开对应论文时会自动复制迁移进来（旧文件保留不删）。

### 6.3 交互细节
- 回答**流式输出**（边生成边显示），随时可按 **停止** 中断。
- **还没有输出时显示「思考中…」**（静态文字，不会闪）；第一段文字到达后自动替换成正文，**不再有闪烁光标**。
- **输出过程默认跟随最新内容往下走**。你往上滚去看前面内容时会停止跟随，右下角出现一个悬浮的 **「↓」** 按钮；
  点一下按钮就回到最新位置并继续跟随；输出结束按钮自动消失。
- **第一次打开某篇论文**（还没加载过）时，正文区会显示「正在打开《…》」的加载提示，首屏画出来自动消失；
  已经打开过的论文切回来是热切换，不显示这个提示。
- 换论文后，上一篇的划词气泡（释 / 译 / ＋对话）、译文浮卡、引用卡片都会收起/重算，不会拿着上一篇的选区提问。
- Markdown 完整渲染：标题、列表、表格、代码块、引用。
- **公式**用 KaTeX 渲染（`$行内$`、`$$独立$$`）。
- **引用可点**：回答里出现的 `〔p.12〕` 是页码按钮，点击跳到第 12 页；如果模型标注了原文片段（`〔p.12‖…原文…〕`），页码按钮后面会**把那段原句显示出来**（普通文字，可以选中复制；片段里有公式也会正常排版），点击直接定位到那一句 / 那一段并画**柔和苔绿的高亮**（不是橙色，也不会只画开头几个字——整句都会盖住）。扫描件或文本层对不上时自动退化为只跳页，不会报错。跳转是**一次到位、不闪动**：页面已经显示时不会重新渲染，位置已经在眼前时也不会来回滚动。
- **点标签也能定位**：回答上方的「第 N 页」标签、以及回答里的原文引用块，点一下同样会跳到文中并高亮对应原文。
- **取消高亮**：在正文任意处点一下、或再点一次同一个引用按钮（开关式）；翻页 / 切换论文时自动清除。**`Esc` 不再用于取消高亮**（它现在是退出全屏的键）。高亮**不会自动淡出**，方便你对照原文慢慢看。
- **每次提问带什么**：问题本身 + 设置里的默认发送范围（整篇 / 联网）+ **所在页上下文** + 最近 3 轮对话。答案条下方的页码标注就是这次的「所在页」。
- **连贯追问直接回答（默认开，可在设置 →「交互与发送」关掉）**：明显接着上一轮问的短问题（例如「那它的核心方法是什么？」
  「为什么有效？」「继续讲讲优缺点」），只要没加选区 / 截图，就直接用对话里已有的内容回答：
  **不再重新翻页、不再带页图、不再跑多轮工具思考**，只发一次流式请求，速度明显更快。
  **以下情况会自动切回完整阅读流程**（真的去翻页 / 读其它页 / 联网）：问题里出现「查 / 搜索 / 核实 / 确认 / 翻页 /
  第 N 页 / 前面几页 / 其他页 / 原文 / PDF / 论文里 / 到底 / 重新生成」等字样；上一轮刚直答完，你只回一个「？」
  或「去查啊」这类质疑；点回答下方的「重新生成」。升级后的那一轮会重新调工具读材料，答案上方的
  「本次依据」也会从「接着上一段对话」变成「AI 自行读取 p.X…」。
  直答轮里模型**不会**再说「我没有联网通道 / 我读不了页图 / 你自己去贴材料」——它只会说明本轮依据上文，
  并提示你说一句「查一下」即可切完整流程。扫描件里问到图 / 表 / 公式时仍保留页图。
  关掉这个开关后，所有问题都会重新读材料（更慢，但每次都会核对原文）。
- **「所在页」怎么定**：有选区 → 选区那一页；问题里说了「第 5 页 / p.5」→ 那一页（哪怕你正看着别的页）；**追问**（「为什么」「它」「继续」）→ 沿用上一轮话题所在的那一页，不会因为你滚到别页就换成屏幕页；都没有 → 你眼前这一页。只有明说「这里 / 这一页 / 当前页」时，才用屏幕页。
- 每条回答下方有动作条：复制、重新生成、页码标记等（显示哪些可在设置里关）。
- **「重新生成」随时可用**：生成完的回答（包括刷新后恢复出来的回答、读懂论文的教学结果）下方都有
  **重新生成**；点它就用同一个问题 / 同一份材料原样重跑一遍。被停止或失败的回答下方是重试按钮。
- **明显只是要翻译的提问就只翻译**：例如「把下面这段翻译成中文：…」这类问题，AI 只给译文，
  最多再用一句话点出关键术语或语气，不会展开结构梳理、背景知识或长篇讲解。
- 生成过程中顶部停止按钮可用；超时会明确报「超过 N 秒没有收到任何数据」而不是一直转圈。
- **右下角浮动提示只在出问题时出现**：成功类操作（保存、复制、移动、切换/新建会话、调整字号等）不再弹提示；
  只有出错、未保存、需要重新操作等问题会弹。AI 功能命中当前会话里属于这篇论文的结果时会直接定位过去；
  没命中就直接重新生成，不会只弹一句「已生成」。
- **上游偶发失败会自动重试一次**：模型接口偶尔返回 503/网络断开（还没开始输出内容时），程序会等 0.9 秒
  自动重试一次；还是失败才显示「接口暂时不可用」和重试按钮。已经开始输出或你主动停止的不会重试。

### 6.4 记忆：会话内 / 本篇论文 / 长期

三层记忆互相独立，全部只存本机：

| 层 | 记什么 | 怎么用 | 在哪里控制 |
|---|---|---|---|
| **会话内** | 最近 3 轮原样带上（每条带「当轮原文 · 第 N 页」）；更早的内容压成**滚动摘要**继续带 | 长会话不会忘记早先的要求和结论；追问能接上文 | 自动；会话文件里的 `summary` 字段 |
| **会话摘要（全局）** | 每个会话结束时的摘要汇总；新会话第一轮参考「之前的讨论」摘要 | 换会话 / 关掉软件再打开接着聊不用重复背景 | 会话历史面板底部的「本篇对话记忆」开关 |
| **身份（自动）** | 你明确自述的称呼 / 名字、研究方向、长期目标（如「我叫 Cyan」） | 与论文无关也常驻注入，可跨论文、跨重启直接称呼你 | 说「忘记我的称呼记录」即可删除；不展示条目（后台维护） |
| **长期** | 你手写的背景与要求（如「我在读多模态方向」「先给直觉再给公式」） | 每次问答和「读懂论文」都会带上 | ⚙ 设置 →「长期记忆」 |

> 问答会话跟着当前「换论文时对话怎么接」的选择走：默认按文件夹（文件夹内切标签不换会话，所以「会话摘要」这一层在文件夹内共用）；
> 选「按论文」时每篇论文各有一段，关闭软件再打开也能接着那篇的前文；选「全局共用」时所有论文共用一段。
> 想换话题可在会话头点 **＋** 新建一个会话。译文不受影响（仍按论文各自保存）。

另外还有**后台学习记忆**（§5.6）：自动观察你的身份自述、讲解偏好和理解边界，不显示条目、不用手动确认。
这些记忆都不是论文证据，回答论文事实仍以论文原文为准；设置里清空长期记忆即可立即失效。

## 7. 截图与长截图

用于把**图 / 表 / 公式**交给 AI 识别（PDF 里的图不是图片文件，只能这样取）。

1. 点顶栏 **⎚ 框选** 按钮，或按 `R` —— 阅读区出现十字光标与提示条。
2. 按住拖出要识别的区域，松手即完成。
3. **拖到阅读区上下边缘会自动滚动**，可以一路框到下一页 → 这就是**长截图**，跨页的表格也能整块取下来。

> 长截图是**从 PDF 按页重新渲染**出来的（不是屏幕截屏），所以缩放不是 100%、双页模式、
> 一次框好几页时，内容依然从页面顶端/左端准确接入，不会出现错位漂移或大块空白带；
> 双页模式只会截取选框所在的那一列（不会把旁边一页也拼进来）。（2026-11-05 修复）

4. 图会加进对话框，可继续打字提问（例如「这张表的结论是什么」）。
5. **也可以只发截图、什么都不写**：怎么回由 AI 判断——它会在**内部**先看截图里实际是什么（图 / 表 / 公式 / 代码 / 手写 / 正文），
   以**这张截图本身为中心**决定这次该识读原文、解释含义、翻译，还是说明它在上下文里的作用；
   但**判断过程不会写出来**：回答直接进入内容，不会先来一段「截图是什么 / 这一小块位于第 N 页底部」的版面描述
   （除非你自己问的就是「这是什么 / 在哪一页」）。
   它只依据截图里看得见的内容回答，看不清就说不确定，不会编，也不会顺手把整篇论文讲一遍。
   问答区只显示你的截图，不会把你没打过的提示词当成「你的问题」显示出来。
6. 取消：按 `Esc`，或再点一次 ⎚ 按钮。
7. **拖在页面外面（左右灰边 / 页与页之间的空白）松手不会有反应**：不会弹「选框太窄」之类的提示，
   也不会生成截图（2026-11-05 修复）；只有选框确实碰在页面内、但拖得太窄时，才会提示往左右多拖一点。

> 输入框左侧的 **✂** 按钮是同一个入口。

> 想**翻译框选的区域**而不是加进问答：切到右栏「译文」面板，用面板顶部的 **⌖ 截图翻译**
> 按钮（或在该面板按 `R`），截图会先放进译文底部输入框，按 `Enter` 翻译，结果进译文面板并带缩略图。见 §4.5。

**截图会跟着会话一起留着**：截图在**点发送**时单独存到 `data/attachments/` 下（会话文件里只记一个编号引用），所以重开论文 / 重启程序后，历史提问里的截图仍然在，也能直接「重试这次发送」。这些图片文件跟着会话走：

- 清空当前会话 → 这次会话的截图一起删掉；
- 删除某个会话 → 那个会话的截图目录一起删掉；
- 发送失败、没写进会话的临时图，会在下一次保存会话时自动清理。

（老版本保存的会话里只有「有过截图」的标记、没有图片本体，那些旧消息仍会显示「截图附件未保存，请重新添加截图」。）

## 11. 工作台布局：停靠 / 换栏 / 应用内卡片

右栏有 **译文** 与 **问答** 两块，规则是「**一栏只开一个**」。

### 11.1 入口
右栏**底部**是唯一一组切换器（`译文 | 问答`）：
- 点没开的那个 → 在本栏打开它（同栏原来那个自动收起）；
- 点正开着的那个 → 收起它。

### 11.2 开工第二栏
右键切换器 → 「再开一栏」：右栏分成两栏，可以**同时**开译文和问答。两栏宽度都能拖。

### 11.3 浮出成「应用内卡片」
- 右键切换器 → 「在应用内卡片中打开」；
- 或**按住切换器往外拖**。
- 卡片可以自由拖动、右下角拖拽缩放（最小 260×180）、点标题把它提到最前。
- **点正文或其他区域不会关掉卡片**；只有三种方式收回：
  1. 卡片标题栏的 **✕**；
  2. 面板管理器里的明确操作；
  3. 按 `Esc`（需先点一下卡片/在卡片里操作过）。
- 卡片**不会**变成系统级独立窗口 —— 所有展开都在阅读器内部，避免盖住正文。

### 11.4 顶部左右栏开关
顶栏中间有两个按钮，分别**收起 / 展开左栏与右栏**，状态随实际布局同步。

### 11.5 面板管理器
**右键任意面板标题栏**打开：
- 每个面板一行：名称、当前停靠位置、显示开关；
- 展开「布局设置」可：浮出 / 停靠到左 / 右 / 底部 / 固定 / 排序 `↑` `↓`；
- 批量操作：「全部显示」「全部收回停靠」；
- `Esc` 关闭。

## 12. 设置项逐条说明

⚙ 打开设置：**左边一列竖排分类，右边显示所选分类的具体设置**。

| 左侧分类 | 右侧设置 |
|---|---|
| **模型与接口** | 已保存的模型配置、API Key、模型名、视觉模型、接口地址 |
| **外观与字号** | 主题、阅读字号（改完立即生效） |
| **交互与发送** | 双指缩放速度、发送范围的两个默认值、连贯追问直接回答（默认开） |
| **会话** | 换论文时对话怎么接（按文件夹 / 按论文 / 全局共用）、AI 自动标题、打开文件夹时的默认动作、历史面板默认排列（改完立即生效，每项下面有「选了之后实际会怎样」的说明） |
| **长期记忆** | 写给 AI 的长期背景与要求 |

- 弹窗记住上次停留的分类，下次打开直接回到那一页；
- 键盘 `↑` / `↓` / `←` / `→` 或 `Home` / `End` 可在分类间循环切换；
- 底部是统一操作栏：「恢复默认设置」在左、「保存」在右，保存后的**连通性测试结果**显示在保存按钮左边。

### 12.1 模型与接口
| 项 | 说明 |
|---|---|
| **API Key** | 你的模型密钥（必填才能用 AI）。支持 OpenAI 兼容接口。**留空 = 保持原来的密钥不变**；框里显示「已保存，留空则不改」就说明已经存过了 |
| **模型名** | 例如 `deepseek-flash`、`openai/gpt-4o` 等，按你的服务商填写 |
| **视觉模型（可选）** | 截图与扫描件页图要交给能读图的模型；填视觉模型名（如 `gpt-4o`、`Qwen/Qwen2.5-VL-7B-Instruct`）。留空 = 用主模型；主模型不支持图片时会报错并提示换模型 |
| **接口地址** | 点「改接口地址」展开。默认 DeepSeek；换 OpenRouter / 本地模型等都在这里改 |

**「保存」按钮自带连通性测试**：点下去会先存配置，再真的发一次请求，把结果写在按钮右边 —— 成功显示 `✅ 模型名 · 耗时ms` 并自动关窗；失败显示 `❌ 具体原因`，可以照着改。所以不需要额外找「测试」按钮。

### 12.2 外观与字号

| 设置 | 作用 |
|---|---|
| **主题** | 跟随系统，或选择六套配色：米宣（暖白）、白瓷（纯白）、青瓷（浅灰绿）、乌木（暖灰深色）、石墨（中性深灰）、玄墨（纯黑，适合 OLED）。玄墨的深色界面使用纯黑底，无阴影。PDF 纸面保持明亮。 |
| **阅读字号** | 12–30px，AI 结果正文的字号（与界面字号独立）；拖滑杆即时生效，`Ctrl/⌘ + =` / `-` / `0` 也能随时调 |

> 其它视觉旋钮（结果密度、代码大小、结果最大宽度、透明度、纸张背景、显示页码 / 原文引用等）已全部下架，
> 不再出现在成品界面；老存档里的这些值仍会被沿用，不会被偷偷改掉。

- **恢复默认设置**（底部左侧）—— 样式与布局一起回默认：主题、阅读字号、六个面板的停靠 / 顺序 / 显隐 / 折叠 / 大小、两侧栏宽度与底部高度、收起意图全部复位。**只动"壳"：论文、对话、消息一条都不碰**，API Key / 模型名 / 接口地址也不动。

### 12.3 交互与发送

- **双指缩放**：缩放速度 0.5–2×（默认 1.0×）。触摸屏捏合、触摸板捏合都乘这个倍率，拖完立即生效，不用重开论文。
- **发送范围默认值**：「整篇论文」「联网搜索」两个勾选是问答发送范围的**唯一入口**（发送框旁的临时切换按钮已于 2026-11-04 移除）；
  改完立刻生效，输入框下方那行提示会说明这次实际会带什么（见 §6.2）。
- **连贯追问直接回答**（`reader.followUpDirect`，默认开）：明显承接上一轮的短问题直接用前文回答，
  跳过重新翻页 / 页图 / 多轮工具思考，速度明显更快；但问题里带「查 / 翻页 / 第 N 页 / 前面几页 / 其他页 /
  原文 / PDF / 核对」等核对词、对上一轮只回「？」、或点「重新生成」时，会自动切回完整阅读流程真正去查
  （不会让模型说「我没有能力，你自己去贴」）。关掉后每个问题都重新读材料（见 §6.3）。

### 12.4 长期记忆

- **长期记忆**：多行文本框，写你希望 AI 长期记住的背景与要求（≤4000 字），保存在本机
  `data/config.json`，随每次问答 / 教学一起发给模型。它只是背景说明，**不会**被当成论文证据；
  清空并保存即可立即失效。后台自动学习到的「理解边界」是另一套（§5.6），不需要也不支持在这里编辑。

### 12.5 会话

会话的运作方式都收在这里，**改完立即生效**，不用重开软件。它只决定「换论文 / 打开文件夹时接上哪一段对话」，
已有会话始终留在历史面板里，**不迁移、不删除**；每项下面都有一行「选了之后实际会怎样」的说明，切换选项即时更新。

| 设置 | 实际体验 |
|---|---|
| **换论文时接哪段**（`reader.session.scopeMode`） | `按文件夹`（默认）：同一文件夹里的论文接着同一段对话——文件夹内换论文不打断、助手带着前文，只有打开另一个文件夹才按下面「打开文件夹时」执行；适合把一个课题的多篇论文当成一段长讨论。`按论文`：每篇论文各接自己那一段对话，换论文不会把上一篇的问答带过去、会话头显示这篇论文的会话；适合逐篇精读，想跨论文比较时临时切到「全局共用」。`全局共用`：所有论文接同一段对话，换论文、换文件夹都能接着上一句问；适合把整个书库当成一段连贯的阅读笔记，代价是各论文的上下文会混在同一段历史里 |
| **AI 自动生成标题**（`reader.session.aiTitle`） | 默认开启。会话有第一轮完整回答后后台生成一次清晰标题（≤28 字）；手动改名永远优先，已生成过的会话不再请求模型，断网也不会一直重试。关掉后会话头沿用首条问题摘要，仍可随时手动改名 |
| **打开文件夹时**（`reader.session.onEnter`） | `先让我选择会话`（默认）：打开一个文件夹（或启动应用）时出现选择卡片，由你挑一段继续；`继续上次的会话`：自动接上最近一段有内容的会话（超过 7 天没更新或超过 60 条仍降级为卡片，避免误开太旧的对话）；`总是新开会话`：每次打开文件夹都新建一个空会话，旧会话留在历史里。**三档只在真正打开文件夹时生效**（切换文件夹 / 从首页进入 / 关掉整个文件夹后再打开 / 重启），同一文件夹里换论文不会重新触发，交给「一段对话属于」自动接上 |
| **历史面板默认排列**（`reader.session.historyMode`） | `按文件`（每篇论文下列出问过它的会话，组头有论文名、路径、会话数）/ `按时间`（最近活动在前）。同一会话在多个存储键下的副本会按 sid **合并成一行**（优先当前归属键那份，只标一个「当前」徽标），行内直接列出按顺序读过哪些论文（「读过 ①论文A ②论文B」）。历史面板始终列出**全部**会话，跨归属方式、跨文件夹的旧会话也能直接打开（打开时自动复制到当前归属方式下，旧文件保留） |

> 四个值分别存在 `reader.session.scopeMode` / `reader.session.aiTitle` / `reader.session.onEnter` / `reader.session.historyMode`。
> 切换「一段对话属于」时当前这段对话会先按旧方式存盘，再把同一个会话接到新方式下（内容复制一份，旧文件保留作备份），不会丢会话。
> 一句话选法：**逐篇精读 →「按论文」；一个课题多篇一起读 →「按文件夹」；想跨论文接着问 →「全局共用」**。

| 拖动面板标题栏 | 拖离 24px 以上松手 = 浮出成应用内卡片；原地松手 = 放回原处 |
| 拖动分隔条 | 调左栏 / 右栏 / 底部停靠区尺寸（`↑↓` 键可微调）|

### 13.4 通用
| 键 | 作用 |
|---|---|
| `Esc` | **按顺序**只关一件事：退出全屏 → 框选 → 设置 → 搜索 → 笔记 → 浮层 → 面板管理器 → 收回卡片 → 停止生成 → 清掉选区（引用高亮不用 Esc 取消；文件多选也会被 Esc 清空）|

| `Tab` | 顶栏、面板、菜单、对话框内完整键盘可达（焦点可见）|

## 15. 常见问题与排错

**Q：AI 功能报「接口没有接受密钥」？**
⚙ 里检查 API Key 是否正确、是否过期；点「测试」验证。

**Q：一直转圈？**
不会。超过空闲时限（默认 60 秒没收到任何数据）会明确报「超过 N 秒没有收到任何数据，已判定为卡住并中断」，并提示可以换模型。

**Q：报「该模型在你所在地区不可用」？**
这是服务商的地区限制，不是密钥失效 —— 换模型或换服务商。

**Q：顶栏找不到了？**
它默认悬停才出现：把鼠标移到**屏幕最上沿**。或 ⚙ → 顶栏 → 改「常驻」。

**Q：PDF 里有图，AI 说看不到？**
用 **⎚ 框选**（或 `R`）把那一块框下来加进对话 —— PDF 的图是画在位图里的，必须这样取。
如果整篇都是扫描件，问答会自动带页面图；但前提是设置里有能读图的模型（见 §12.1）。

**Q：扫描版 PDF 划不了词 / 搜不到字？**
扫描件没有文本层，划词和全文搜索本来就不可用；问答与「读懂论文」会自动按页面图片理解（§5.7）。
需要精确引用原文时，用框选截图（§7）交给视觉模型识别。

**Q：AI 好像记得之前聊过什么？**
同一会话会带最近几轮和滚动摘要；新建会话时会参考这篇论文之前会话的摘要；
⚙ 里的「长期记忆」每次都会带上。会话历史面板底部的「本篇对话记忆」可以关掉跨会话摘要（§6.4）。

**Q：AI 说图片请求失败 / 不支持图片？**
设置里「视觉模型」留空时，图片会发给你填的主模型；有些文本模型不支持读图。
填一个视觉模型名再试（§12.1），或改用框选后让主模型看——不行就换模型。

**Q：打开文档时弹「Unexpected server response (NNN)」或「打开失败」？**
这是浏览器内核在取本地 PDF 时，本地文件服务没有返回正常状态（不是论文损坏，也不是网络问题）。常见原因有两个：
1. **同一份 PDF 连续拖入好几次**：旧版会反复重写同一个文件，正在打开的窗口可能读到写了一半的内容。新版已改成
   「同名同大小直接复用、写入用临时文件再原子替换」，重复拖入不再重写；打开失败时也会先自动重试一次。
2. **同时开了两个阅读器窗口**：两个窗口共用同一份 `data/`（含 WebView2 缓存），会互相抢占。新版**同一个数据目录
   只允许开一个窗口**（见 §1），第二个实例会直接退出并把已打开的窗口提到前台。
遇到时：关掉多余的窗口后重试打开；新版错误提示里也会写明状态码和可能原因。

**Q：测试/重新构建会不会把我正在用的阅读器关掉？**
不会。测试只启动 `test/artifacts` 里的副本（后台模式，窗口不显示），构建脚本也不会按进程名杀进程；
桌面上的 exe 正在运行时，`build.bat` 会提示「被占用、已跳过」，关掉后重跑即可更新。

**Q：深色模式下 PDF 还是白底？**
这是刻意的：PDF 保持白纸黑字（深底黑字没法读），变深的是界面外壳。

**Q：卡片挡住正文了？**
卡片可以拖走；点卡片标题栏的 ✕、或在面板管理器里收回、或先点一下卡片再按 `Esc`。卡片不会因为点别处而消失（这是有意的，避免误关）。

**Q：想复用/备份我的数据？**
整目录拷走即可：`data/`（配置、笔记、阅读状态）+ `papers/`（论文库）。

**Q：不填 API Key 能用吗？**
能。PDF 阅读、目录、搜索、笔记、框选截图全部可用；只有 AI 相关的动作需要密钥。

## 16. 多标签工作区 / 依据回执 / AI 自行读取（2026-11-01 更新）

### 16.1 多标签工作区（B 线 P1）

- 打开过的论文会在正文上方排成**标签条**（顶栏下面那一行），点标签切换；标签上限 **10 个**。
- **关掉最后一个标签 = 回到首页（Welcome）**：书架页可见、两侧栏收起、底栏禁用；从首页再打开论文，标签条回来。
- 关闭：标签上的 `×`、**鼠标中键**、**Ctrl+W**。重新打开刚关掉的：**Ctrl+Shift+T**。
- 切换：**Ctrl+Tab / Ctrl+Shift+Tab**、**Ctrl+PageDown / Ctrl+PageUp**、**Ctrl+1…Ctrl+9**（9 = 最后一个）。
- 排序：按住标签左右拖动；顺序会被记住。标签条右侧 `⌄` 菜单分三组：**全部标签** →
  **当前文件夹/书架里未打开的论文** → **全部已导入文件（其他文件夹，按需打开）**
  （默认只列当前文件夹；想读别的文件夹里的论文，从这个菜单直接点开即可）。
- **切回已经打开的标签不重新加载**（保留页码/缩放/聊天状态，切回来几乎瞬间完成），刷新/重启才会重新读 PDF。
- **切换论文不会重绘右侧问答栏**：问答会话是所有论文共用的，切标签/开新论文时聊天区的内容、滚动位置原样保留（只换译文那一块）。
- 刷新/重启会恢复上次的标签列表与当前标签；本地拖进来的临时文件不在书架里，刷新后不恢复（可在首页重新拖入）。
- 全屏（F11 / 顶栏 ⛶）时标签条隐藏，专心读当前这篇。
- 想同时看多篇论文：右键书架里的论文，或右键正文标签，选「在新窗口打开」；也可以**直接把标签从标签条拖出**，松手即在新窗口打开这篇（等同「移到新窗口」）；标签右键另有「移到新窗口」（新窗口加载成功后才关原标签）。每个窗口的标签、页码、缩放、会话互相独立，可随时拖动、平铺或移到其他显示器；顶栏「窗口」菜单可切换、平铺或「保存窗口布局并退出」，下次启动整组恢复。同一会话/译文/笔记可以在多个窗口同时编辑，保存后自动同步到其它正显示同一内容的窗口。详见 `docs/多窗口阅读.md`。

### 16.2 每条回答的「本次依据」（A 线 P1.5）

- 回答正文上方有一行**只读小字**：`本次依据：p.3 选区 / 当前页 p.8 / 整篇原文 …`，
  让你一眼看出这次回答用了哪些材料；它不可点，也不需要操作。
- 引用页码是**程序核验**过的：页码超出本次材料范围/超出总页数的引用不会变成按钮（保持原文文字）；
  页码对但正文里核对不上原句的引用，会降级成带 `?` 的纯页码按钮——**只跳页，不会画假高亮**。
- 判错对象时不需要特殊按钮：直接用正常追问纠正即可（例如「我指的是当前页这一页」「不是这个人」）。

### 16.3 AI 自己决定读哪几页（A 线 P2.5，默认开启）

- 对**文本型 PDF 的纯文字问题**，AI 会先用只读工具自己检索/翻页（最多 5 轮、每轮最多 4 个工具），
  再基于读到的页回答；回答只会引用它**真正读过**的页。
- **读错页 / 页不够时它会自己继续读**：比如按目录页码找页时发现 PDF 页码有偏移、或读到的页不对，
  它会立刻改用正确页重读，**不需要你催**，也不会把错页将就成材料。
- **扫描件会自动读图**：在扫描件上调「读第 N 页」会直接把这页原图加进材料（不会先报一条「没有文本层」的失败）；
  同一页重复读取会提示「原图已经在材料里」，不会重复附给模型。也不会用「需要我接着读下一页吗」结尾——
  需要就直接读，不需要就把答案给完。
- **工具调用过程不会出现在回答正文里**：极端情况下模型把工具调用写成了特殊标记文本，程序也会把它剥离/还原成工具调用；
  轮次用完时会直接告诉你「工具轮次已经用完」并基于已读材料回答，不会假装材料已经读够。
- **扫描件直接读页面图**（不再逐页做 OCR 转写）：第一次问也不用等「逐页转写」，程序只做页型判定（有缓存）+ 渲染页图；
  AI 问「这一页/整篇」时直接把相关页原图交给模型（最多 5 页），不再逐条播报「已加入第 N 页原图」。
- **能直接读 papers 文件夹里所有已导入的论文**（不用先打开那篇）：你说「读 papers 里第一篇论文的第二句话」，
  它会先列出 papers 里的文件（顺序 = 左侧文件树顺序，「第 N 篇」按这个数），再读指定页正文并原样引用；
  扫描件/没有文本层时它会取该页原图。当前打开的论文照旧用「读当前页 / 检索本篇」。
- **过程只显示一条笼统状态**（不再逐条列工具调用细节）：生成时回答上方只有一行
  `正在查阅论文材料…`，完成即收起；不会逐条写「正在列出 papers 文件夹…」「已加入第 N 页原图」这类明细。
  回答正文同样不会汇报操作过程（见 §16.7）。
- **其它论文的页码标签可以直接点**：回答里写成 `《某论文.pdf》p.3` 的标签，就算那篇论文还没打开，
  点一下也会**自动打开它并跳到第 3 页**；带原文片段的会画出高亮。
- 回答里引用原文时会显示成**左侧竖线的引用块**（不是普通的 `>` 字符）。
- 带截图 / 加进对话的文字提问时，AI 也可以自己继续用工具查页（截图只是附加材料）；
  只有「只发截图没写问题」时不会额外跑工具，交给模型直接判断。
- 模型不支持工具调用、超时或出错时会**静默回退**到旧的「预装材料」路径：过程列表整块撤掉，你只会看到正常的回答。
- 想临时关掉这个能力：浏览器开发者工具执行 `localStorage.setItem('reader.agentRead','0')` 后刷新；
  恢复默认：`localStorage.removeItem('reader.agentRead')`。
- 同理，多标签工作区可整体退回旧单文档行为：`localStorage.setItem('reader.tabs','0')`（应急用）。

### 16.4 会话与文件夹 / 译文怎么存（2026-11-03 会话系统 P0；2026-11-04 修订）

- **一次只处理一个文件夹**：左栏「文件」上方有当前文件夹按钮 `📁 papers/…`，点开可以换文件夹；
  换文件夹 = 关掉旧文件夹的标签 + 进入新文件夹的会话（文件仍可以在文件夹之间转移，拖拽/「移动到…」不变）。
- **换论文时对话怎么接可调（2026-11-04 修订）**：⚙ → 设置 →「会话」→「换论文时接哪段」，改完立即生效（`reader.session.scopeMode`）。
  它决定的是**连续性**（换论文时接上哪段对话），不是「会话归谁所有」——历史面板始终列出全部会话，任何模式都不会删改旧会话：
  - `按文件夹`（默认）：同一文件夹里的多篇论文共用同一批会话；文件夹内切论文**不换会话、不打断**，只有打开另一个文件夹才按「打开文件夹时」执行；
  - `按论文`：每篇论文各有一份自己的会话（存储键就是论文 docId），换论文自动接上**那篇论文上次的对话**，
    不会把上一篇的问答带过去；会话头、选择卡片、☰ 快速切换都只显示这篇论文的会话；
    想跨论文比较、让助手带着前文追问时，临时把设置切到「全局共用」即可；
  - `全局共用`：问答统一存在同一段对话里，换论文、换文件夹都能接着上一句问。
  切换归属方式时当前对话会先按旧方式存盘，再把同一个会话接到新方式下（内容复制一份，旧文件保留作备份），
  旧会话仍留在历史里（**不迁移也不删除**），不会丢。会话历史面板统一列出**所有文件夹、所有归属方式**的会话，
  跨文件夹 / 跨归属方式点开会自动切到对应文件夹并打开那篇论文（旧归属下的会话会先复制到当前归属方式，原文件保留）。
- **同一会话的多份副本在历史里只显示一行（2026-11-04 修订）**：切换「换论文时对话怎么接」会在新旧存储键各留一份，
  历史面板按 sid 合并成一行（优先当前归属键那份，只标一个「当前」徽标；标题、置顶、归档取合并后的值），
  删除时会连同所有副本一起删掉，不会删完又「复活」。
- **跨论文 / 跨归属方式切换时的防护（2026-11-04 修订）**：历史面板开着的时候切换论文或切换
  「换论文时接哪段」，列表会自动按最新数据重新读取、合并，不会再把旧论文的行留在面板里、
  也不会把别的论文的行标成「当前」；「当前」只在**当前归属方式 + 当前这篇论文**的那份副本上出现。
  点击历史里的会话优先**在当前论文里原地接上**（当前论文问过这段对话、或当前归属方式下已有副本时都不换文档）；
  只有当这段对话确实没问过当前论文时，才按行里记录的论文顺序切换到对应论文（跨文件夹同理）。
  切换模式下复制到新归属方式的副本会保留完整论文清单与全部对话内容，不会只剩当前这篇论文。
- **「打开文件夹时」的三档只对真正打开文件夹生效（2026-11-04 修订）**：不自动恢复上次会话，而是根据设置把
  「继续上次『标题』」主按钮、**＋新建会话**、最近几条会话放到眼前（默认），或直接恢复 / 直接新建。
  只有**切换文件夹 / 从首页进入 / 关掉整个文件夹后再打开 / 重启应用后首次打开**才算「打开文件夹」；
  **同一文件夹里换论文不算**——不会重新弹卡片、也不会另开新会话，而是按上面的归属方式静默接上（文件夹会话 / 那篇论文自己的 / 全局共用的）。
  首次发消息后会话才落盘，所以不会堆空会话文件。
  - 进入方式三档（设置 →「会话」→「打开文件夹时」，也保留历史面板 / 选择卡片底部切换，存 `reader.session.onEnter`）：
    `choose`＝默认选择卡片；`resume`＝自动恢复上次（超过 7 天没更新或超过 60 条时仍降级为卡片）；
    `new`＝每次打开文件夹都新会话。
- **会话头**：问答栏顶部显示当前会话标题 + 状态点（AI 正在生成时亮起）+ **＋**新建 + **☰**历史。
  标题右侧弹出的会话列表范围随「一段对话属于」变化：`按论文` 只列这篇论文的会话、`按文件夹` 列当前文件夹的、
  `全局共用` 列所有论文共用的那批；历史面板不受此限制（始终列出全部）。
  标题由服务端先取首条问题（最多 28 字）兜底；**AI 自动标题**开启时，第一轮完整回答后后台让模型概括一个
  简短干净的标题（提示词要求中文 ≤14 汉字，最终硬上限 28 字，会清掉引号/书名号/句末标点），
  手动改名（`titleSource='user'`）永远优先、不会被覆盖；已生成过的会话不再请求模型；关掉开关后只保留首问标题（`reader.session.aiTitle`）。
  可在历史面板里双击或点铅笔改名。`按论文` 下「本篇对话记忆」只汇总这篇论文自己的旧会话摘要，不会掺入同文件夹别的论文。
- **历史面板（☰）有两种排列**（切换后会被记住，存 `reader.session.historyMode`）：
  - **按文件**：按「在哪些论文里问过」归组——**文档（论文）组头是独立卡片**：左侧方形论文图标 + 加粗论文名 + 会话数胶囊，
    下面一行小字是 `papers/路径`；组与组之间用虚线分隔。会话行**再缩进一级**、左侧有竖直引导线，
    每行行首还有一个小圆点（当前会话是强调色），和上面的文档组头一眼区分开；同一会话在每篇问过的论文下**各出现一次**，
    组按最近活动排序；没关联任何论文的会话收在最后「未关联论文」组。会话行标题用界面字号，
    另用胶囊标出「当前」（只在第一处出现，同一会话不会多行同时标「当前」）；
    多论文会话在行里直接用「读过 ①论文名 ②论文名」列出顺序（最多 3 个，悬停看完整）。
    `全局共用` 模式下所有会话只分一组「共用会话」，组头卡片同样式，副标题直接写出读过哪几篇论文。
  - **按时间**：全部会话按更新时间倒序（置顶 / 今天 / 昨天 / 最近 7 天 / 更早 / 已归档），
    每个分组标题右边有**会话数量**；每行下面用「读过」标签 + **编号圆点**标出按提问顺序问过哪几篇论文
    （最多 3 个，悬停看完整顺序）。
  两种排列都支持搜索（标题 / 预览 / 论文名）、行内重命名、置顶、归档（归档≠删除，可随时取消）、
  删除（应用内确认；删了不可恢复）；标题行会标明当前「换论文时接哪段」模式（按文件夹 / 按论文 / 全局共用），
  面板底部有**会话设置**入口，直达设置里的「会话」分类。
- **生成中守卫**：AI 正在生成时点新建 / 切换 / 删除 / 换文件夹会被拦住并提示，不会弄丢正在生成的内容。
- **打开论文、浏览别的会话不会刷新会话时间**：列表排序只在会话内容真正变化时更新。
- **文件夹改名 / 移动后会话跟着迁移**：改名文件夹、把文件夹拖到别处后，里面的会话与附件自动复制到新位置
  （旧文件保留作备份），正在使用的「当前文件夹」也会同步更新。
- **译文按论文各自保存**：每篇论文的划词/整篇译文单独归档；清空当前会话只清问答与 AI 结果，不动译文。
- **AI 功能记录跟着会话走（2026-11-03 修订）**：新会话会清掉「深入阅读 / 读懂论文」的已生成记录；
  再点同一项时——当前会话里**有这一篇论文的这条结果**就直接定位过去（闪一下）不重复生成；
  **没有就重新生成**。结果按论文校验，不会把别的论文 / 别的会话的旧记录当成命中；
  菜单不再显示「已生成」、也不再变色。想重跑点结果下方的「重新生成」。
- **跨文件夹读取默认关闭**：AI 默认只读当前论文 / 当前文件夹；只有你明确点名其它论文（文件名、「第 N 篇」、
  别的文件夹、「其它论文」）它才会去读别的文件夹。
- **旧数据自动迁移**：以前「每篇论文一份会话」的旧记录会复制进所属文件夹的会话；
  旧版「全局共用会话」在启动时按每条消息的 docId 拆到对应文件夹（复制不删旧文件，只做一次）。
- **想改连续方式 / 打开策略 / 历史排列 / 自动标题**：⚙ → 设置 →「会话」里直接选（见 §12.5），每项下面写着选完之后的实际效果；
  也支持手动设置 `localStorage.setItem('reader.session.onEnter','resume')`＝自动恢复上次、`'new'`＝总是新会话、删掉该键＝默认选择卡片；
  `localStorage.setItem('reader.session.scopeMode','paper')`＝按论文、`'global'`＝全局共用、删掉该键＝默认按文件夹。
- 想退回旧行为：`localStorage.setItem('reader.tabs','0')`（多标签关闭）；`localStorage.setItem('reader.agentRead','0')`（AI 读取关闭）。

### 16.5 快捷键补充

- `Ctrl+W` 关闭当前标签；`Ctrl+Shift+T` 重开最近关闭的标签；
  `Ctrl+Tab` / `Ctrl+Shift+Tab`、`Ctrl+PageDown` / `Ctrl+PageUp` 切换标签；`Ctrl+1…9` 直达第 N 个标签。
- `Ctrl/⌘+Shift+N` 新建会话；`Ctrl/⌘+Shift+H` 打开会话历史面板；
  浏览器里 `Ctrl+Shift+N` 可能被无痕窗口占用，此时用备用组合 `Ctrl/⌘+Alt+N` / `Ctrl/⌘+Alt+H`。
- 输入框里打字时这些组合仍然生效（不会误触发「全选后发送」）。

### 16.6 译文截图翻译（2026-11-03）

- **入口**：右栏「译文」面板顶部工具栏 **⌖ 截图翻译**；译文面板里按 `R` 也走这个入口。
  框选后**截图先放进译文底部输入框**（和问答加图一致），再按 `Enter` 连同输入框里的文字一起发送翻译。
  问答面板按 `R` / 输入框旁 ✂ 仍是老行为（框选后加进问答附件）。
- **链路**：框选 → `viewer.captureRegion` / `captureRange` 得到 PNG → 先 `uploadAttachment`
  存到 `data/attachments/<会话键>/<32 位 id>.png` → 以多模态消息（`image_url` part）发给模型。
- **提示词**：`public/js/prompts/capabilities/translate.js` 的 `translate.screenshot`
  （v1.0.0，`multimodal: 'image'`）；要求按阅读顺序翻译可见文字、公式变量数字引用编号原样保留、
  图表为主时补「图表说明：…」、看不清标注「…」不猜造、只输出译文。目标语言跟随输入框旁
  「译成」的选择（默认中文，2026-11-05 起不再写死）。
- **存储**：结果条目照常进该论文的译文会话（`doc=<docId>&sid=__translate`）；
  条目额外记 `screenshot: true` 与 `shots: [{id,w,h,label}]`，重试描述 `retry.kind='translate-shot'`
  （带 docId/sid/page/label/refId），因此失败/停止后点「重试截图翻译」会按附件 id 取回原图重跑，
  不用重新框选；刷新/重启后 `restoreSession` 会 hydrate 缩略图并恢复重试。
- **样式例外**：译文块默认隐藏 `.acts`（保持界面干净），截图翻译条目加 `msg-shot-translate` 类，
  单独放开「重试截图翻译」按钮的显示（`style.css` 里对应 override）。
- **提示词黄金基线**：新提示词没有加入 `test/_prompts.mjs` 的 `SCENARIOS`（那里是固定场景清单），
  所以 `test/fixtures/prompts-baseline.json` 无需变更；本轮按用户要求**未运行 test/ 正式套件**，
  仅用 `test/artifacts/smoke-shot-translate.mjs` 手动冒烟（32/32 通过）。

### 16.7 翻译能力增强与过程精简（2026-11-03）

- **译文文本输入改为常驻共享 composer**：译文面板底部一直显示输入框，与问答共用输入区；
  面板切换时更新占位提示和发送行为。输入最多 2 万字，目标语言中文 / English（记在
  `localStorage reader.translate.targetLang`），`Enter` 翻译、`Shift+Enter` 换行；截图翻译仍从译文工具栏进入。
  结果以翻译专属卡片展示方向、原文和译文，并可复制译文；`retry.kind='translate-text'`
