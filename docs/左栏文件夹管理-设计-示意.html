关键操作

拖拽PDF 拖到文件夹行 = 移动到该夹；夹内拖拽 = 调顺序；从资源管理器拖文件夹 = 建同名夹并导入
右键文件夹：新建子夹 / 重命名 / 删除（非空可选「PDF 移到根再删」）；PDF：移动到文件夹
双击双击文件夹名直接重命名（内联改名，改磁盘真实目录）
筛选输入关键词 → 树变扁平结果，前缀显示所在文件夹；清空恢复树
×行尾删除按钮：只删 PDF 文件，笔记 / 会话 / 进度保留
存储：文件夹 = papers/ 下的真实子目录，资源管理器里直接可见可改；顺序写 data/papers-order.json（升级为相对路径数组，旧数据自动兼容）。
数据安全：docId 只依赖文件名 → 移动文件不丢笔记 / 会话 / 阅读进度；同名自动加 (2)，保证一个 docId 对应一份数据。
删除按钮：× 默认隐藏，鼠标移到该行才显示；中性灰（非红色），hover 加深。文件夹行不设 ×，删除走右键菜单。
