# 右栏交互增强 — 设计方案

> 状态：已实现（2026-11-01；划词气泡 `test/right-select.mjs` 18/18，引用高亮 `test/citation-quote.mjs` 28/28）
> 范围：① 右栏译文 / 问答文本支持划词气泡（加入对话 + 直接解释，样式同正文）；② 答案引用从「跳页」升级为「跳段 / 跳句 + 高亮」；③ 引用高亮的取消方式。

## 1. 右栏划词气泡

### 1.1 现状

划词气泡（#bubble）只绑定在 PDF 正文（#viewer）的选区上；右栏译文 / 问答的文本选中后没有任何操作入口。

### 1.2 设计

- **触发**：在右栏 `.msg .text`（译文 / 问答回答）中选中文字、松手后 → 显示**与正文同一个气泡组件**（样式完全一致）；
- **按钮子集**（按需显隐，同一容器）：

  | 按钮 | 右栏是否显示 | 行为 |
  | --- | --- | --- |
  | 加入对话 (add) | ✅ | 把选中文本作为 selection 加入当前问答会话（来源标注为「右栏译文/回答」） |
  | 直接解释 (explain) | ✅ | 把选中文本发去做解释（进入问答，语义同正文 E 键） |
  | 复制 (copy) | ✅ | 复制选中文本 |
  | 翻译 (translate) | ❌ 隐藏 | 右栏译文/回答再翻译无意义 |
  | 写笔记 (note) | ❌ 隐藏 | 笔记需要正文锚点，右栏不适用 |

- **定位**：气泡位置用 `window.getSelection().getRangeAt(0).getBoundingClientRect()`（右栏选区没有正文那种跨页 rect 结构，直接用 DOM 选区矩形）；
- **页码（2026-11-01 修订）**：原设计写「`page` 取当前阅读页」，实测会被误当成「第 N 页原文」
  （模型拿上一轮回答里的解释文字去对照那页的手写内容，才发现对不上）。现改为**右栏选区 `page = null`**，
  附件行只标「右栏」不标页码；提问时 PDF 语境按当前屏幕页整页给，`selectionSource='right'` 让提示词明确
  「来自右栏回答 / 译文，不是论文原文」。
- **交互细节**：
  - 气泡按钮 `mousedown` 防选区丢失（现有逻辑通用，不用改）；
  - 滚动右栏**不**误关气泡：现有 scroll 监听按 `#viewer` 判断收起，需把右栏 `#aiArea` 滚动排除在外（或仅当滚动元素是正文 / 文档级时收起）；
  - 选区消失（点击别处 / Esc）时气泡收起，与正文一致；
  - 右栏选区的 `sel` 对象：`page` 取当前阅读页（无正文选区时）；`box` 为空——`addToChat` / `doExplain` 需兼容无 `box` 的 selection（仅展示与加入对话，不画正文选区块）。

## 2. 引用精确定位（p3 → 句 / 段级）

### 2.1 现状

模型回答里引用原文用 `〔p.N〕` / `〔p.N–M〕`，渲染成可点击页码按钮（`.page-ref`），点击只能**跳页**（`jumpToPageWithHistory`）。

### 2.2 升级：标注带原文片段

- **新标注格式**：`〔p.N‖原文片段…〕` —— 页码 + `‖` + 连续一句 / 短段原文（≤120 字）；
- **渲染**：`decoratePageRefs` 升级识别新格式：
  - 有片段 → 渲染为同款按钮 **+ 按钮后面把片段原文显示出来**（`.quote-inline`，普通文本可选中复制），`title` 仍显示片段全文（hover 可读）；
    ⚠️ 初版只把片段塞进 `title`，正文只剩 `p.5`——用户实测「老师写下的答案是：p.5 p.5 p.5 p.5，本来有文字的，渲染之后被吞掉了」，已按此修正；
  - 无片段（旧格式 `〔p.N〕`）→ 维持现状（纯跳页），**向后兼容**；
- **点击行为**：跳到第 N 页 → 在该页文本层内定位片段 → 画**临时高亮**（`.quote-hit`）；
  - 定位改为「去掉空白的整串匹配」：先整句精确匹配；对不上时用最长前缀定起点、再用**句尾回找 + 贪心延伸**定终点，
    高亮覆盖**整句**（不再只画开头几个字）；
  - **跨页续画**：片段在换页处被切开时，第一页画完后按「这一页吃掉的字符数」把剩余部分接到下一页继续画
    （最多向后 3 页；页面之后才渲染出来也会在重画时补上）——用户反馈「换页的地方只能显示第一页的」，已修；
  - 跳转一次到位：即时跳页（不做平滑滚动动画）、**只有目标页还没渲染时才等渲染**，
    已渲染的页面绝不 `refreshPage` 重建（之前每次重建画布 → 用户反馈「连点同一个 p1 按钮会闪」）；
    片段已经在视口内时不再滚动，连点同一引用不会来回晃；
  - **0 命中**（扫描件 / 文本层与提取文本不一致）→ 自动退化为纯跳页，不报错；
- **点标签也定位**：回答上方的「第 N 页」标签（`.pg`）和原文引用块（`.ref.ref-jump`）点击后同样跳到文中并高亮
  （优先用这条消息里同一页的带片段引用，没有就用消息自带的原文引用）；
- **Prompt**（`ai.js` 各 messages）：增加一条指令——「引用论文原文时，用 `〔p.N‖原文片段〕` 标注，片段必须是论文里连续的一句或短段，不超过 120 字」；
- **渲染兼容**：`p.` 前后空格、半角/全角竖线（‖ / ‖ / ｜）、长破折号都能识别；
  片段里含 `$...$` 公式时保留行内 KaTeX（不再显示 HTML 标签），片段长度上限按「可见文字」算；
- **高亮样式**：`.quote-hit` 用和应用主色一致的**柔和苔绿半透明块**（`rgba(125,158,80,.20)` + 底部细线），
  不要橙色描边框；与搜索（黄）和选区（暖沙）区分，虚拟化重画时保留。

## 3. 取消高亮

**三种方式任选其一，行为一致、不自动消失：**

1. **点击正文任意处** → 清除（与「取消选区」的既有肌肉记忆一致，最直觉）；
2. **再次点击同一个引用按钮** → toggle（点开再点关）；
3. 翻页 / 切换文档 / 重新打开 → 自动清除。

> **2026-11-01 修订**：`Esc` 不再用于取消高亮（Esc 现在是退出全屏的第一优先级快捷键）。

另：
- 翻页 / 切换文档 / 重新打开 → 自动清除；
- **不做自动淡出**（用户可能要细读原文对照，淡出会打断阅读）。

备选（若用户不认可上面）：
- 高亮块右上角加小 ×，点击清除（多一个可点目标，稍显冗余）；
- 滚动离开当前页时清除（滚动本身就是"看完离开"的信号，但可能误伤——滚回来看高亮没了）。
