# 多窗口阅读

- 书架文档右键选择“在新窗口打开”。标签右键可选择“在新窗口打开”或“移到新窗口”，也可以直接把标签拖出标签栏——拖出即把这篇论文移到新窗口；移动会在新窗口成功加载后才关闭原标签。
- 窗口可以自由拖动、缩放、最大化或移到其他显示器。顶部“窗口”菜单支持切换窗口、平铺所有窗口。
- 各窗口独立保存标签、阅读位置、布局和当前会话；新窗口不自动接管原窗口的对话，可以同时打开不同会话分别问答。
- 已打开的同一会话会同步提问和回复。生成期间，其他窗口显示等待提示，回复完成后更新正文。同一篇论文的译文和笔记也会同步。问答和译文按条目合并，笔记以最近一次保存为准。
- 发送消息时使用的材料（引用、截图、当前阅读上下文）取自发送消息的那个窗口。
- 关闭窗口只关闭自身；关闭最后一个窗口退出程序。使用“窗口 → 保存窗口布局并退出”，下次启动恢复整组窗口。普通关闭的窗口不再加入恢复列表。
- 最多同时打开 10 个窗口；每个窗口仍可使用多个标签。浏览器版提供新标签页/新窗口入口，窗口平铺和整组恢复由桌面 EXE 提供。

开发验收：`node test/multiwindow.mjs` 使用隔离 EXE 副本、合成 PDF 和 WebView2 CDP；不会启动或关闭用户的阅读器，也不会写入用户数据目录。
