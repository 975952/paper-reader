## 九、「右边被挡住」的定位办法（给下一个会话 / 给用户）

已经量化确认的事实（1440×900、译文有内容、深色与浅色都测过）：

| 检查项 | 结果 |
|---|---|
| 右栏区域内打点 774 个，最上层**不属于**译文块的 | **36 个（5%）**，且全部是右栏自己的切换器 `#aiBar` / `.aibar-btn` |
| `.page` 右缘 vs 右栏左缘 | `pageRight=951`、`sideLeft=1080` → **PDF 比右栏左缘还靠左 129px，没有交叠** |
| `.float-layer` | `pointer-events:none`，且子元素（浮窗）已被限制在 `.viewer-wrap` 内 |
| 深色下右栏底色 | 原 `rgb(33,31,26)`（亮度 8%，像黑块）→ 现 `rgb(46,43,36)`（亮度 43%） |

所以**默认布局下右栏没有被压**。若用户仍看到遮挡，属于**特定窗口尺寸或特定状态**，请按下面两步定位：

1. **让用户 F12 → Console 粘这段**（一次就能指名道姓）：
   ```js
   (()=>{const vw=innerWidth,vh=innerHeight,out=[];const block=document.querySelector('.ai-block[data-block="translate"]');
   const has=(el)=>!!(block&&block.contains(el));let n=0,bad=0;const who=new Map();
   for(let y=46;y<vh-20;y+=16)for(let x=0;x<vw;x+=16){n++;const h=document.elementFromPoint(x,y);
   if(!h)continue;if(!has(h)&&h.closest('.side.right')===null){bad++;const k=`${h.tagName.toLowerCase()}${h.id?'#'+h.id:''}.${String(h.className).split(/\s+/)[0]} z=${getComputedStyle(h).zIndex} bg=${getComputedStyle(h).backgroundColor}`;
   who.set(k,(who.get(k)||0)+1)}}
   const side=document.querySelector('.side.right');const sr=side&&side.getBoundingClientRect();
   const msg=[`视口 ${vw}x${vh} body="${document.body.className}"`,`右栏左缘=${sr&&Math.round(sr.left)} 宽=${sr&&Math.round(sr.width)}`,
   `非右栏元素压住右栏区域: ${bad}/${n}`,...[...who.entries()].sort((a,b)=>b[1]-a[1]).slice(0,6).map(([k,c])=>`  ${c}× ${k}`)];
   console.log(msg.join('\n'));alert(msg.join('\n'))})()
   ```
2. **同时问清两件事**：窗口有多大（是否 <1000px）、译文是不是刚从别处（浮窗/第 2 栏）切过来的。

**注意**：窄窗（≤980px）时右栏会被压到 60px（`body.side-squeezed`，这是刻意设计：宁可压窄 + 正文横向滚动，也不整条隐藏）。如果用户在窄窗下把"只有 60px 宽"当成"被挡住"，那要改的是**交互提示**（比如压窄时在栏上给一个"展开"按钮），不是遮挡逻辑。
