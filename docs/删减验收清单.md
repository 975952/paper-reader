# 论文阅读器删减验收清单

这份清单用于验收删减施工结果。它只判断产品行为和代码收口，不要求保留旧的布局契约。

## 1. 先确认施工边界

- [ ] 改动前存在 `backup/radical-trim-before-*` 完整备份。
- [ ] `data/`、`papers/` 没有被改动。
- [ ] 没有先改测试断言再宣称通过。
- [ ] 所有前端改动最后都重新执行了 `desktop\\build.bat`。

## 2. 主干功能必须保留

在隔离目录打开合成 PDF，逐项确认：

- [ ] 打开本地 PDF、切换论文、翻页、跳页正常。
- [ ] PDF 缩放、适应宽度、全文搜索正常。
- [ ] 目录跳转正常。
- [ ] 笔记可以新建、编辑、删除、按页跳回。
- [ ] 选中文本可以翻译、解释、加入问答、复制。
- [ ] 问答默认只发送选中文本和当前页上下文。
- [ ] 失败、停止、重试、会话恢复仍然正常。
- [ ] 公式、表格、代码块仍然正常渲染。
- [ ] 正文引用可以跳到参考文献并返回原位置。
- [ ] API Key、模型名、接口地址仍然可以保存和测试。

## 3. 右栏收口验收

### 必须成立

- [ ] 默认只有一个右栏。
- [ ] 右栏只有“译文 / 问答”两个标签。
- [ ] 点击当前标签是 no-op，不会把面板收起来。
- [ ] 点击另一个标签只切换内容，不改变正文宽度和左栏状态。
- [ ] 翻译结果自动显示在译文标签。
- [ ] 解释和自由提问自动显示在问答标签。
- [ ] 右栏宽度不足时，正文不会被压到 0 宽。
- [ ] 520px 窄窗口仍能看到可用正文区域。

### 必须不存在

- [ ] `rightCol2`、`aiArea2`、`panelDockRight2` 不再进入运行时 DOM。
- [ ] 不再有“第 1 栏 / 第 2 栏 / 再开一栏”的用户入口。
- [ ] 不再有右栏自动在多个位置复制同一结果。
- [ ] 不再通过 `visible`、`col`、`rightCols.count` 多处互相覆盖来决定当前标签。

## 4. AI 功能删减验收

- [ ] 顶栏只保留少量文档级操作，最多 4 个。
- [ ] 不再显示“更多操作”分组菜单。
- [ ] Coach 模式不出现在正式界面。
- [ ] “整篇”不再是常驻按钮；选择全文前有明确提示。
- [ ] “联网”默认关闭，且必须明确显示外部资料来源。
- [ ] 重复点击同一 AI 操作不会重复发起请求，除非用户明确选择重新生成。
- [ ] AI 结果只保留一个正式结果区，选区旁不再出现完整答案浮层。
- [ ] 没有 API Key、请求失败、上游超时都有明确状态，不显示假成功。

## 5. 面板系统删减验收

- [ ] 不再有面板管理器高级布局菜单。
- [ ] 不再有固定、换位、拖出、停靠到底部、跨栏移动等入口。
- [ ] 不再有应用内浮动面板或拖拽停靠预览。
- [ ] 左栏只保留文件、目录、笔记和简化后的参考文献入口。
- [ ] 左栏图标点击只做一件事：打开对应面板。
- [ ] 顶栏收起按钮和活动栏恢复按钮语义一致。

## 6. 设置和正式产品边界

- [ ] 设置页只暴露 API、主题、阅读字号等低数量核心设置。
- [ ] 不再暴露结果透明度、结果最大宽度、控件缩放、代码字号等视觉实验参数。
- [ ] 不再显示禁用但仍占位置的顶栏设置。
- [ ] 不再显示“系统级独立窗口”“面板停靠”“面板固定”等已删除功能文案。
- [ ] Android、VPS、个人工具说明不再出现在正式产品入口或主 README 的使用路径中。

## 7. 代码收口检查

用 `rg` 检查以下遗留项。若仍存在，必须说明是兼容代码还是删除遗漏：

```text
panelWindow
detachedWindows
openPanelWindow
detachPanelToWindow
rightCol2
aiArea2
panelDockRight2
right-col2-off
renderCols
renderCol(2)
floatLayer
dockPreview
topbarHot
uiTopbar
data-wry-drag-region
```

兼容代码必须满足：

- [ ] 不会被正常用户路径调用。
- [ ] 不会创建隐藏状态或写入旧状态。
- [ ] 有明确注释说明删除计划或迁移原因。

## 8. 测试顺序

先跑行为，再迁移契约：

1. `node --check public/js/app.js`
2. `node test/ux.mjs`
3. `node test/selection.mjs`
4. `node test/stream.mjs`
5. `node test/left-rail.mjs`
6. `node test/panels-right.mjs`
7. `node test/cards.mjs`
8. `node test/e2e.mjs`
9. `cmd /d /c desktop\\build.bat`
10. `node test/desktop.mjs`

测试失败时先判断是产品回归、旧断言，还是测试脚手架问题；禁止直接删断言。

## 9. 交付判定

只有同时满足下面三点，才算删减完成：

1. 主干阅读功能全部通过。
2. 删除项从用户入口和运行时状态两侧都消失。
3. 浏览器验证和重新编译后的桌面版验证结果一致。

仅仅把按钮隐藏、把旧函数改名、或让旧测试变绿，都不算完成。
