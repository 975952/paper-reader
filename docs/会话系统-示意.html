这次重新设计的 7 件事

  1. 会话头：标题即入口（点开快速切换），右边是 新建 ＋ 与 历史 ☰；状态点显示生成中 / 未读 / 失败。
  2. 历史面板：全高覆盖层，搜索 + 本文件夹/全部文件夹 + 时间分组 + 置顶 + 已归档折叠。
  3. 默认策略（用户拍板 B，可设置）：进文件夹默认显示空态选择卡片——「继续上次会话『…』」 +「新建会话」+ 最近会话，不自动恢复；设置里可改成“自动恢复上次”或“总是新会话”。 这与 VS Code 1.108 一致：入口和最近会话一眼可见，又不把长对话硬塞回来。 刷新页面即可回到这张卡片（本示意初始状态就是它）。
  4. 行内管理：双击 / F2 重命名；⋯ 菜单置顶、归档、导出、删除；删除走应用内确认。
  5. 空态：新会话显示「开始一段新对话」+ 继续上次 + 最近会话。
  6. 归档 ≠ 删除：归档收进折叠区可恢复；删除才永久删内容与截图；新建 ≠ 清空（新建不删旧会话）。
  7. AI 结果不再被会话切碎（配套改动，不在本示意里）：别的会话做过「深入阅读」时提示可直达或重算。
  8. 草稿保留：每个会话记住没发出去的输入，切换/重开回来还在。
