### 真实输出

**它要解决什么问题**

这篇论文处理「序列转换」（sequence transduction）：把一个序列变成另一个序列，最典型的是机器翻译——输入英文，输出德文。当时最强的做法是编码器-解码器（encoder-decoder）结构：编码器把输入压成一串向量，解码器再一个词一个词地生成输出，主力是循环神经网络（RNN，按时间顺序一步步处理序列的网络）〔p.2〕。

瓶颈在「顺序」。RNN 算第 t 个位置的隐藏状态 $h_t$ 时必须等 $h_{t-1}$ 算完，即 $h_t=f(h_{t-1},x_t)$，所以同一个句子内部无法并行，序列越长越慢，显存又限制了靠增大 batch 补偿 〔p.2〕。另一条路是卷积网络（ConvS2S、ByteNet），能并行，但让任意两个位置建立联系所需操作数随距离增长，ConvS2S 是线性、ByteNet 是对数 〔p.2〕。注意力机制（attention，处理某个位置时去「看」其他位置）此前几乎总和 RNN 搭配 〔p.2〕。论文要问的是：能不能把循环和卷积全扔掉，只靠注意力？

**一个具体例子**

（教学例子，不是论文实验）翻译 "The cat that the dog chased ran away" 时，要译对 "ran" 的主语是 "cat" 而非 "dog"，模型必须把相隔几个词的 "cat" 和 "ran" 联系起来。用 RNN，这个信息得沿 $h_1\to h_2\to\cdots$ 一步步传，中途容易衰减，而且第 6 个词必须等前 5 个算完。用注意力，"ran" 可以直接和句中每个词比对一次，一步取到 "cat" 的信息，所有位置还能同时算。论文附录的可视化正是这类现象：第 5 层多个注意力头把 "making" 和远处的 "more difficult" 连了起来 〔p.13〕。

**原来的办法卡在哪**

不是旧方法效果差，而是代价结构不对。其一，顺序计算是硬约束：RNN 每层需要 O(n) 次串行操作（n 为序列长度），自注意力只需 O(1) 次 〔p.6〕。其二，长距离依赖难学：信号在网络中要走的路径越长，梯度越难传回，RNN 的最大路径长度是 O(n)，卷积是 O(log_k n)，自注意力是 O(1) 〔p.6〕。其三，卷积方案每层计算量 $O(k\cdot n\cdot d^2)$，比自注意力的 $O(n^2\cdot d)$ 更贵，且仍不能让任意两位置一步相连 〔p.6〕。旧方法要么不能并行，要么并行但路径长、代价高。

**作者的办法**

先给直觉（类比）：把一句话想成圆桌会议，每个词手里有一份自己的表示。轮到某个词更新自己时，它先问「在座谁跟我有关」，每个词按相关程度报一个分数，它再按分数加权，把大家的内容汇总成新表示。全程没有先后顺序，所有词可以同时发言。

正式名称是 Scaled Dot-Product Attention（缩放点积注意力）〔p.4〕。输入分成三组向量：query（Q，我在找什么）、key（K，我能提供什么线索）、value（V，我实际携带的内容），三者由同一序列经不同线性变换得到。核心公式：

$$\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^{T}}{\sqrt{d_k}}\right)V$$

$QK^T$ 是每对 query 与 key 的点积，可理解为相关度打分。形状上，若序列有 n 个词、每个 key 是 $d_k$ 维，Q 和 K 都是 $n\times d_k$，$QK^T$ 就是 $n\times n$ 的打分矩阵，第 i 行第 j 列表示第 i 个词对第 j 个词的关注分数。除以 $\sqrt{d_k}$ 是因为维度大时点积会很大，把 softmax 推到梯度极小的区域，训练不动 〔p.4〕。softmax 把一排分数变成一排正数、且加起来等于 1 的权重，分数高的份额大。最后用这些权重对 V 加权求和得到输出 〔p.3–4〕。

单个头会把不同位置的信息平均掉，所以论文用 Multi-Head Attention（多头注意力）：把 Q、K、V 各用不同的线性投影映射 8 次，得到 8 组 64 维版本，并行做 8 次注意力，再拼接投影回去 〔p.5〕——相当于 8 个视角分别盯不同的关系。另外，模型里没有循环也没有卷积，天然不知道词序，所以要把正弦/余弦位置编码加到词向量上 〔p.6〕。整体是编码器和解码器各堆 6 层，每层含自注意力和逐位置前馈网络，外套残差连接与层归一化；解码器自注意力加了掩码，防止看到尚未生成的位置 〔p.3〕。

**结果和边界**

WMT 2014 英德翻译上，big 模型拿到 28.4 BLEU（机器翻译常用质量分，越高越好），比此前最好结果（含多模型集成）高 2 BLEU 以上 〔p.1, p.8〕；英法拿到 41.8，为当时单模型最好，8 块 GPU 训练 3.5 天 〔p.1, p.8〕，base 模型只需 12 小时 〔p.2〕。训练成本约 $2.3\times10^{19}$ FLOPs，此前强模型在 $10^{20}$–$10^{21}$ 量级 〔p.8〕。消融显示：单头注意力比最佳设置差 0.9 BLEU，头太多也掉；缩小 key 维度损害质量；dropout 对防过拟合很有用；正弦位置编码换成可学习位置嵌入结果几乎一样 〔p.9〕。英语成分句法分析上，WSJ 单语料 91.3 F1、半监督 92.7 F1，超过 BerkeleyParser，但低于 RNN Grammar 的 93.3 〔p.10〕。

仅凭这些结果还不能确定：论文只做了翻译和句法分析两类任务，作者把扩展到图像、音频、视频列为未来计划 〔p.10〕；对超长序列，作者提出把注意力限制在局部邻域，但明确留待未来研究 〔p.7〕；注意力可视化只被当作附带好处，论文没有给出因果性结论 〔p.7〕。另外正文一处把英法成绩写成 41.0 〔p.8〕，与摘要和表 2 的 41.8 〔p.1, p.8〕不一致。

### 真实输出

**注意力机制的基本框架（Attention / Query–Key–Value）**
- 是什么：把当前要处理的一个位置当成一个 query，拿去和序列里每个位置的 key 比对相似度，相似度当权重，对所有位置的 value 做加权平均，得到这个位置的输出。
- 用在哪里：第 2 页说 attention 早已是序列模型的标配、只是通常和循环网络一起用；第 3 页把 attention 定义成「query 与一组 key-value 对到输出的映射」；第 5 页列出本文的三种用法（编码器自注意力、解码器自注意力、编码器-解码器注意力）。缺了这个框架，第 5 页这三种用法和附录里的注意力可视化〔p.13–15〕都读不进去。
- 够了的标准：能用自己的话说清「同一句话里每个词互相查」是 self-attention，「解码器的位置去查编码器的所有位置」是 encoder-decoder attention，就够；不需要事先懂加性注意力（additive attention）的公式，也不需要懂它的训练细节。
- 门槛：现在必须懂。档案记录（2026-10-20）：「只听过名字，不知道 Q/K/V 分别代表什么」——缺的正是这一层框架，而不是某个变体。

**Softmax 与点积的数值尺度**
- 是什么：softmax 把一组实数变成一组正数、且加起来为 1 的权重；点积越大表示两个向量方向越接近。
- 用在哪里：式 (1) 整条就是 $\mathrm{softmax}(QK^T/\sqrt{d_k})V$〔p.4〕；第 4 页解释为什么要除以 $\sqrt{d_k}$，并给了「q·k 的方差等于 $d_k$」的推导；第 5 页解码器的掩码是把非法位置的分数设成 $-\infty$ 再送进 softmax。
- 够了的标准：能说清「先取 e 的幂、再除以总和」这一步，并能解释为什么设 $-\infty$ 会得到 0 权重、为什么分数整体变大时分布会变尖锐，就够；不需要会推 softmax 的反向传播，也不需要懂数值稳定的工程实现。
- 门槛：现在必须懂。档案记录（2026-10-24）：「softmax 里的指数归一化说不清楚」——差的就是上面这一步，其余概率论内容不用先补。

**张量形状与线性投影的跟踪**
- 是什么：把一批 query、key、value 分别摞成矩阵 Q、K、V 之后，注意力就是一次矩阵乘法加一次加权求和；多头是把这个过程并行做 h 次再把结果拼回来。
- 用在哪里：第 4–5 页定义 $d_{model}=512$、$h=8$、$d_k=d_v=d_{model}/h=64$ 以及 $W_i^Q$ 等投影矩阵的维度，第 5 页给出 Concat 后再乘 $W^O$；第 6 页表 1 的复杂度、第 9 页表 3 里改 $h$、改 $d_k$、改 $d_{model}$ 的那些行，都要靠这套形状换算才读得懂。
- 够了的标准：能在纸上写出 $QK^T$ 的形状、说出「8 个头各 64 维拼起来正好是 512」、并说出改 $h$ 时 $d_k$ 怎么跟着变，就够；不需要会矩阵求导，也不需要自己写高效 kernel。档案里 PyTorch 写过 CNN 的经验足够覆盖代码和训练循环层面，不构成门槛。
- 门槛：现在必须懂。档案记录（2026-09-12）：「矩阵乘法会算，但形状变化时容易绕晕」——缺口正好落在这一层形状跟踪上。

**自回归解码与序列任务的评测口径**

**残差连接、层归一化与 dropout 这一套训练配件**

- 门槛：可以之后再学。读第 3.1 节时顺手补一页就能过，不补也不影响理解注意力本身。

### 真实输出

**它是什么**

Softmax 是一个把“任意实数分数”变成“非负且总和为 1 的权重”的函数。你先有一组分数 $z_1,\dots,z_n$，softmax 对每个分数取指数，再除以所有指数之和：

$$ \mathrm{softmax}(z_i)=\frac{\exp(z_i)}{\sum_{j=1}^n \exp(z_j)} $$

指数 $\exp$ 的作用是：把负数也变正，同时把大分数放大得更突出；除以总和则保证所有输出加起来是 1。所以它输出的不是“分数”，而是可以当权重用的比例。

教学例子：分数 $[2,1,0]$。取指数约 $[7.39,2.72,1]$，总和 $11.11$，归一化后约 $[0.665,0.245,0.090]$。最高分 2 拿到约 66.5% 权重，最低分 0 只拿 9%。如果分数变成 $[10,0]$，权重会接近 $[0.99995,0.00005]$，几乎全压在最高分上——这就是“饱和”。

**为什么这篇论文需要它**

论文的注意力核心公式是

$$ \mathrm{Attention}(Q,K,V)=\mathrm{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V $$

〔p.4〕。这里 $Q$、$K$、$V$ 是注意力里的查询（Query）、键（Key）、值（Value）；现在只需把 $QK^T$ 看成“每个查询和每个键之间的原始分数”。softmax 把这些分数变成权重，再对 $V$ 加权求和。论文对注意力的文字定义也是：输出是 values 的加权和，权重由 query 与对应 key 的兼容函数算出 〔p.3–4〕。没有 softmax，就没有“权重”。

另外，解码器要防止看到未来位置，论文的做法是把非法连接的分数设为 $-\infty$，再送进 softmax 〔p.5〕。因为 $\exp(-\infty)=0$，这些位置的权重就是 0。

### 真实输出

**公式 (1) 在算什么**

一句话直觉：它算的是「某个 query 该从各个 value 里各取多少信息」，输出是 value 的加权平均。

论文对 attention 的定义是：attention 函数把 query 和一组 key-value 对映射成输出，query、key、value、输出都是向量；输出是 value 的加权和，权重由 query 与对应 key 的「相容性」函数算出 〔p.3–4〕。公式 (1) 就是这套话的矩阵写法：

$$\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

逐个符号：

- $Q$：query 矩阵，$n$ 行，每行一个 query，每行维度 $d_k$。
- $K$：key 矩阵，$m$ 行，每行一个 key，维度也是 $d_k$。
- $V$：value 矩阵，$m$ 行，每行一个 value，维度 $d_v$。
- $d_k$：query/key 的维度，不是序列长度。
- $QK^\top$：分数矩阵，衡量每个 query 和每个 key 有多「合拍」。
- $\mathrm{softmax}$：按行归一化，把一行分数变成一组非负、和为 1 的权重。
- 输出：$n\times d_v$。

**softmax 补一句**（你档案里说这块薄弱）：给定向量 $z$，$\mathrm{softmax}(z)_i=\exp(z_i)/\sum_j\exp(z_j)$。指数保证每项为正，除以总和保证加起来是 1。指数还会放大差距——两个分数差 1，权重比大约是 $e\approx2.72$ 倍。

**形状走一遍**（你说矩阵形状变化容易绕）：$Q$ 是 $n\times d_k$，$K^\top$ 是 $d_k\times m$，所以 $QK^\top$ 是 $n\times m$。它的第 $i$ 行第 $j$ 列，就是第 $i$ 个 query 和第 $j$ 个 key 的点积。softmax 沿最后一维做，于是第 $i$ 行变成 $m$ 个权重。再乘 $V$（$m\times d_v$），得到 $n\times d_v$；第 $i$ 行输出 $=\sum_j \text{权重}_{ij}\cdot V$ 的第 $j$ 行。

**一组数值例子**：取 $d_k=2$，一个 query $q=[1,0]$，两个 key $k_1=[1,0]$、$k_2=[0,1]$，对应 value $v_1=[1,0]$、$v_2=[0,1]$。

- 点积：$q\cdot k_1=1$，$q\cdot k_2=0$；
- 除以 $\sqrt{2}\approx1.414$：得 $0.707$ 和 $0$；
- softmax：$\exp(0.707)\approx2.028$，$\exp(0)=1$，和约 $3.028$，权重约 $0.670$ 和 $0.330$；
- 输出 $=0.670\cdot[1,0]+0.330\cdot[0,1]=[0.670,0.330]$。

$q$ 和 $k_1$ 更对齐，所以 $v_1$ 占的比重大。

**为什么除以 $\sqrt{d_k}$**：论文说 $d_k$ 大时点积会变得很大，把 softmax 推到梯度极小的区域。脚注给了推导：假设 $q$、$k$ 各分量独立、均值 0、方差 1，则点积 $q\cdot k=\sum_i q_ik_i$ 的均值是 0、方差是 $d_k$ 〔p.4〕。除以 $\sqrt{d_k}$ 后方差回到 1 附近——这一步是我从脚注直接推的，论文没写「回到 1」这句话。论文还比较了 additive attention（用单隐层前馈网络算相容性）和点积版：理论复杂度相近，但点积版实践上更快更省空间，因为能直接用高度优化的矩阵乘法代码 〔p.4〕。

**Figure 2 左图：Scaled Dot-Product Attention**

**先声明缺什么**：给出的文本里只有图题「(left) Scaled Dot-Product Attention. (right) Multi-Head Attention consists of several attention layers running in parallel.」〔p.4〕，图内的方框文字、箭头标签、连线方向都没有被抽取出来。所以下面我按正文 3.2.1 的描述讲数据流，不声称图里一定这么标。

按计算顺序看（从下往上画是这类图的常见做法，但图内方向文本没给，这算我的推断）：

1. $Q$ 与 $K$ 做矩阵乘，得到分数矩阵；
2. 除以 $\sqrt{d_k}$ 缩放；
3. 可选的一步：mask。论文说解码器自注意力里要把「非法连接」在 softmax 输入处设成 $-\infty$，这样 softmax 后对应权重为 0，从而阻止位置看到右边 〔p.5〕；
4. softmax，得到权重；
5. 与 $V$ 矩阵乘，得到输出。

**Figure 2 右图：Multi-Head Attention**

公式在 p.5：

$$\mathrm{MultiHead}(Q,K,V)=\mathrm{Concat}(\mathrm{head}_1,\dots,\mathrm{head}_h)W^O$$
$$\mathrm{head}_i=\mathrm{Attention}(QW_i^Q,\ KW_i^K,\ VW_i^V)$$

其中 $W_i^Q\in\mathbb{R}^{d_{model}\times d_k}$、$W_i^K\in\mathbb{R}^{d_{model}\times d_k}$、$W_i^V\in\mathbb{R}^{d_{model}\times d_v}$、$W^O\in\mathbb{R}^{hd_v\times d_{model}}$ 〔p.5〕。论文用 $h=8$ 个头，每个头 $d_k=d_v=d_{model}/h=64$ 〔p.5〕。

流程：$Q$、$K$、$V$ 各自经过 $h$ 组**不同**的线性投影，得到 $h$ 套低维版本；每套并行做一次左图的 attention；$h$ 个 $d_v$ 维输出拼接成 $h\cdot d_v$ 维；再经 $W^O$ 投影回 $d_{model}$ 维。

为什么这么做：论文说多头让模型能同时关注不同表示子空间、不同位置的信息，单头做平均会抑制这一点 〔p.5〕。而且因为每个头维度降到 $d_{model}/h$，总计算量和全维度单头差不多 〔p.5〕。

三种用法 〔p.5〕：encoder-decoder attention（query 来自解码器上一层，key/value 来自编码器输出）；编码器自注意力（三者都来自上一层）；解码器自注意力（三者都来自解码器，但带 mask）。

**看图顺序建议**：先看左图，把公式 (1) 的五个步骤对上；再看右图，注意它是「把左图复制 $h$ 份、各自先做投影、最后拼接再投影」——右图里那些并排的小块就是 $h$ 个头，不是 $h$ 个不同层。
